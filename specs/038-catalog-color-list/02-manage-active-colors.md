# 展示管理維護體驗 B 方案

## 範圍與操作

- 使用者於 2026-09-15 確認方案 B：只編輯啟用色、隱藏停用車型、品牌／車型／型號連動篩選。
- 品牌為 brand、車型為 name、型號為 model_number；不混用年份或煞車型式，不變更主檔。
- 僅 active 車款列入管理結果及下拉來源，已上架與未上架皆保留。三條件精確交集，關鍵字維持模糊搜尋；選好後套用，不在每次下拉時送請求。
- 變更品牌清空車型與型號，變更車型清空型號；分頁保留 GET 條件，清除篩選回全部啟用車款。無 JS 仍可送出伺服器篩選。
- 編輯僅 active 車色；每色獨立圖片／上傳／移除區塊，無色提示至機種設定。主圖對應收進進階區，保留既有流程。
- 停用車款的直接 GET／POST 編輯拒絕；驗證後以 transaction 與 row lock 再核對車型、車色及照片狀態；不影響舊圖，不進行檔案刪除。
- 新增 admin-only 私有預覽，沿用 root_required 與登錄路由；公開入口仍要求 active + published，私有預覽不取代公開限制。

## 驗收與發布

- Django：停用／未上架、篩選交集及分頁、車色欄位與非法 POST、狀態競態、同色上傳移除衝突、私有預覽權限、公開未上架拒絕。
- JS：依層級產生正確選項，重複／空型號過濾、上層變更重設下層。
- computer-use：桌面、平板、手機與鍵盤，實際檢查篩選及車色區塊；正式站只讀驗證，不修改商品或訂單。
- 新增相容連動篩選功能，升版 1.6.0，更新受眾規則與使用說明。無 migration；完整 CI、標籤、備份、部署、健康及正式功能驗證。
