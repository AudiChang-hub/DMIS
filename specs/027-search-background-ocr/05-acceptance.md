# 驗收標準

- 10,000 筆索引資料的搜尋查詢 P95 目標小於 300ms。
- 正式頁面搜尋不產生配件、費用、文件之間的笛卡兒乘積。
- OCR 執行期間可繼續填寫，畫面不出現全頁卡屏。
- OCR 完成、失敗、照片更換及工作失效皆有自動測試。
- OCR worker 停止時 Web 與資料庫仍可提供一般操作。
- 新增本國自然人訂單時，身分欄位在 OCR 完成前不顯示。
- OCR 排隊／辨識中有醒目的區塊內狀態提示，完成後自動帶入並展開核對欄位。
- OCR 失敗可改用人工輸入；既有草稿與訂單資料不會被隱藏。
- 正式環境 migration、索引重建、首頁、搜尋與 worker smoke test 全部通過。
