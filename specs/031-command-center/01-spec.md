# 戰情首頁與訂單體驗 B 方案

## 已確認
- 狀態使用文字加語意色塊；桌機、手機、總表、明細一致。
- 自家來源的空白／本店顯示為馭盛，不改實際來源、人員與庫存地點名稱。
- cancelled、cancel_refund_pending 不列成交／淨利；缺日期顯示破折號、不提醒補領牌；已存在日期與原財務、退款、稽核紀錄不變。取消待退款仍列退款待辦。
- 排序直接追加、方向文字化，可單獨移除及提前／延後順位；全部清除另設，保留篩選、每頁筆數，回第一頁。無 JavaScript 亦可操作。
- 首頁提供本月新成立訂單、領牌成交台數、車款成交額、可計入訂單淨利／平均與資料完整度；使用既有單筆淨利公式，不冒稱公司淨利。
- 本月至今日（排除未來日期）比較上月相同日期範圍，遇短月截月底；月底比較完整上月。前期零顯示無比較基準，負數前期以絕對值為分母。
- 近十二月成交台數、成交額、淨利分開圖表與可讀數值表，最後月份標示截至今日；可下鑽總表。空月份顯示零，無可計入淨利顯示缺資料而非零獲利。
- 總表維持逐單核對、成本收支、篩選與匯出；車型彙總降為預設收合，與首頁共用成交／淨利口徑。包含取消只影響明細，不混入成交彙總。
- 收款風險：收款明細應收大於已收為待收；有已收金額且營運收款未確認為待確認；取消待退款顯示預計退訂金。指標與下鑽共用條件、不相加冒稱不重複總數。
- 保留重要工作、庫存異常、期限與牌險差異；最近訂單／動態次要內容收合。
- 沿用 dashboard 全公司統計授權；明細、財務下鑽與異動按鈕逐路由檢查，不放寬權限。
- 配色使用獨立文字與按鈕語意色，涵蓋所有外觀、系統深淺色、focus、disabled；修正底部按鈕與編輯提示對比。
- 同步網頁說明與 USER_MANUAL；SQLite／PostgreSQL、排序 JS、取消與匯出、期間邊界、同口徑、風險下鑽、權限與實際瀏覽器驗證後備份部署。
