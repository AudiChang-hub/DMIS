# 1.12.1 附件與客戶應收修正

依 2026-09-21 新版三頁 PPT 與 B 方案授權。

- 新建表單的同一車主預設不勾；不修改已保存的舊單。勾選同一車主時隱藏並停用三個舊車主上傳欄位，不刪除保存附件。
- 新選的存摺／補充附件在送出前顯示本機預覽，取消或換檔釋放 URL。已存附件置於車主資料區，保留受保護下載及放大。
- 配件「其他」顯示名稱輸入，只供既有調價授權者；贈送前後端均將售價和工資歸零。
- 客戶預估尾款以 balance 收款明細 expected_amount 為準，包含已核定人工調整。無明細的歷史單沿用舊算法，新分期單維持牌險＋配件－訂金（最低零）。不以總分期還款額或公司撥款充當本金。
- 訂單摘要、PDF、交付共用讀取服務。PDF 分期還款總額為每期×期數，獨立於分期外應收；不再用空白申請本金推算尾款。
- 無 migration 或資料回填，不批次變更正式應收、成本、佣金、撥款。發布備份後可回復前一版本程式，無資料逆遷移。
- 驗證：現金／分期、有無明細、人工調整、訂金、確認／短收、PDF與畫面一致、附件授權、其他配件授權與贈送、桌機及手機操作。
