保留現行 Django 資料、OrderProcessor 及其他專案服務。歷史程式可留 Git 追溯，不留舊資料副本。

還原演練：每週自動用正式備份建隔離環境，無主機發布埠、無對外網路，恢復資料庫與
媒體檔案，逐表比對筆數及逐檔雜湊，檢查現行 Django migration、ORM 及健康路由，
成功失敗皆清理暫存資源並保存不含個資的摘要。只開放 superuser，逾期不得顯示通過。

user timer enabled 且 Linger=yes；權限與狀態解析回歸測試通過。沒有宣稱异地整機切換完成。
