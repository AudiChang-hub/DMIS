新版戰情首頁、排序與狀態

  • 戰情首頁看近 12 個月走勢、收款風險與作業卡點；營運總表查逐筆收支及成本；報表中心做車型、通路分析。
  • 本月新成立訂單依成立日期，其餘成交成果依領牌日截至今日。與上月同期比較，月底比較完整月份；上月為零顯示無比較基準。
  • 車款成交額是車款售價合計，不是實際收款。訂單淨利未含公司租金、薪資等全公司費用。待補成本或待核對資料不計入淨利；圖表斷線／破折號代表缺資料，不是零獲利。
  • 收款風險涵蓋所有月份目前未結事項：待收款按應收大於已收；已有收款待確認按實收已登記但營運收款未確認。兩類可能重疊。點指標下方連結查看明細，仍受原畫面權限限制。
  • 訂單表頭直接點擊追加排序，再點切換方向。排序條件列可逐項「移除」「提前」「延後」；「全部清除」才會移除全部。日期顯示新→舊／舊→新，金額大→小／小→大，文字採系統正序／反序。
  • 領牌日期排第一順位時，遞減會把未領牌置前，遞增置後；排序後回第一頁，保留搜尋及篩選。
  • 狀態同時顯示色塊與文字：灰色草稿／取消、黃橙色待處理、藍色進行中、綠色完成、紅橙色退款或補件提醒。自家車行來源顯示馭盛。
  • 取消／已退款與取消待退款不計成交淨利；缺日期顯示「—」，不再催補領牌日。既有日期、收款、退款、費用與異動紀錄仍保留；取消待退款仍須完成退款。
  • 可在外觀選擇深淺色或高對比；顏色不取代文字，鍵盤焦點有外框，停用按鈕仍可辨識。

找不到完全相同的內容。請改用較短的關鍵字，例如把「無法更換配車」改成「配車」。

01

第一次使用

三分鐘認識系統

先記住四件事：首頁看待辦、任何內容都能搜尋、訂單建立後才配實體車、資料有問題不要重複建單。

車輛銷售管理① 使用說明② 檢查更新
③ 戰情首頁④ 全欄位搜尋⑤ 今天的待辦與最近訂單
首頁訂單＋新增營運更多
  1. 登入後先看戰情首頁。優先處理、待配車、進行中與庫存數量都會集中顯示。
  2. 要找資料就直接搜尋。像 Excel 的尋找，不必先選姓名、電話或車牌欄位。
  3. 客人在面前就按「＋新增」。依來源、車主、車輛、金額、需求五區填寫，輸入中會自動保存草稿。
  4. 工作做完才按完成。配車、領牌、交付等完成後會鎖定，避免後續誤改。
手機加到主畫面後看不到新版？先按上方「檢查更新」，確認草稿或修改已儲存，再按「重新載入」。
手機

每個帳號各自設定

手機「更多」與快速前往

  1. 點手機下方「更多」。上方先顯示你自己的快速前往，預設第一個是「價格表分發」。
  2. 按「自訂捷徑」。可挑選 1～6 個常用功能並調整順序，儲存後只套用到自己的帳號。
  3. 需要其他功能時按「查看全部功能 →」。這是完整功能清單，和自訂捷徑是兩個不同入口。
換手機仍會保留設定跟著登入帳號保存，不是只存在目前這支手機。
02

每天第一站

戰情首頁與 Excel 式搜尋

怎麼找

  • 輸入 0912 找電話片段。
  • 輸入 ABC1234 或 ABC-1234 找車牌。
  • 輸入姓名、車型、配件、備註或文件名稱。
  • 搜尋結果會標示「哪個欄位、哪段內容」符合。

怎麼看

  • 先看成交趨勢、淨利完整度與收款風險。
  • 「待配車」是訂單成立但未指定實體車。
  • 「進行中」是配車後至交付完成前。
  • 新成立訂單依成立日，成交成果依實際領牌日；均排除取消／退款。
例子

只記得客人姓「張」且買灰色 SUI 125：先搜「張」，再從結果顯示的車型／車色辨認，不必翻每一張訂單。

搜尋不到

改用部分內容、移除空格或連字號；「最近訂單」只顯示最新資料，要看全部請進「全部訂單」。

03

全部訂單

依狀態查看與繼續處理

  1. 從上方「全部訂單」或手機「訂單」進入。
  2. 搜尋或選擇狀態。篩選只縮小清單，不會改變訂單。
  3. 先看清單摘要。每張訂單直接顯示機種、顏色、領牌日期、車號、淨利、車行／來源及備註。
  4. 依工作量選每頁 25、50、75 或 100 筆。分頁可回第一頁、上一頁、輸入頁碼、下一頁或到最後一頁。
  5. 點訂單列進入工作頁籤。先看狀態、尚缺項目與處理紀錄。
避免重複訂單找不到訂單時，先回首頁用姓名、電話、證號或車牌做全欄位搜尋，再決定是否建立。
04

客人在面前

建立訂單與自動草稿

1來源→2車主→3車輛→4金額→5需求
  1. 來源。本店不需再選名稱；合作車行或網路平台要選正確來源。找不到時先請管理者新增，不要亂選。
  2. 車主與證件。本國自然人、外籍／居留者上傳正反面；法人由人員自行填公司基本資料。
  3. 車輛。選品牌車型、年份與車色。此時不選引擎／車身號碼，建立後才配車。
  4. 金額。選現金、分期或刷卡；分期才會出現公司、期數、開辦費與每期金額。其他費用不是必填。
  5. 需求。選號方式與交車方式必填；配件、汰舊／補助依實際需要填寫。
完整例子

陳小華在本店買 SUZUKI SUI 125／2026／白，現金付款、不申請補助、來店取車：來源選本店；完成證件核對；選車型車色；付款選現金；牌險依單據；交車選來店取車，再按「建立訂單」。

外籍與法人外籍／居留者不需登記護照。法人由人員自行填基本資料；領牌前準備登記證明、核准函、近一期 401、公司大小章，申請補助另備公司存摺。沒有專屬名稱的資料放到對應工作的「其他文件」並清楚命名。

草稿

開始輸入後會自動保存。新建單與重新開啟草稿都能看到「刪除草稿」。刪除會連草稿照片一起移除，無法復原。

正式修改

訂單建立後的修改不會自動保存，必須填變更原因並按「儲存修改」。不想保留就按「取消修改」。

05

證件核對

拍照、OCR 與人工確認

證件正面照片查看・更換・移除
對照
姓名・生日・證號逐字核對後確認
證件反面照片查看・更換・移除
對照
戶籍／居留地址留意巷、弄、樓、房
  1. 選「拍照」或「上傳圖片」。避免反光、模糊、裁切及過斜。
  2. 看到「正在辨識」後可先填其他區塊。不要重複上傳同一張。
  3. 完成後回到車主區逐欄對照。OCR 只是協助輸入，照片才是核對依據。
  4. 有錯就直接修正，再勾人工核對。

文件差異

  • 本國自然人：姓名、生日、證號在正面，地址在反面。
  • 外籍／居留者：主要資料多在正面，但正反面仍都要保存。
  • 法人：系統會提示自行填寫基本資料，不做證件 OCR。

常見辨識錯誤

  • 姓名少一字：看正面照片補齊。
  • 「10樓」變「1樓」：放大反面逐字核對。
  • 正反面放錯：移除後重新上傳。
  • 失敗：重新拍攝，或人工輸入後核對。
06

訂單建立後

工作頁籤不是關卡

訂單建立
配車 → 領牌 → 交付補助資料與文件（可同步）簽署文件在訂單資料內隨時補上

上方頁籤是不同工作區，不必依序全部通過。補助可在還沒配車時先收件；簽署文件不是獨立階段，回到「訂單資料」即可上傳。一般客戶仍須先配車、完成領牌，才可交付。

看「建議下一步」系統會依目前資料提出一項主要建議，並列出最多兩項可同步工作。人在其他頁籤時可點按前往；已位於建議頁籤時會標示「目前作業」，不再顯示重複的前往按鈕。這是操作指引，不會自動替你配車或送出資料。

不想現在處理

  • 按「稍後處理」會縮成一列，不會消失。
  • 按縮小列的「查看」可立即展開。
  • 完成一個階段後，系統會依新狀態顯示新的建議。

例外情況

  • 沒有可售車：引導到快速進車。
  • 合作車行先領車：持續提醒三個工作日內補領牌文件。
  • 取消待退款、逾期文件與收款會優先顯示。
角色交接

業務完成訂單與證件核對 → 行政／庫存完成配車，補助可同步收件 → 行政完成領牌 → 交付人員核對車況與收款 → 財務確認撥款與單筆淨利。每次接手都先看尚缺項目與處理紀錄，不用 LINE 訊息代替系統紀錄。

07

內部協調

配車與更換配車

  1. 進入「配車」。清單只顯示符合車型與車色且可售的車。
  2. 核對識別號碼與實際位置。油車是引擎號碼；電動車、輕型電動車與微型電動車是車身號碼。
  3. 按確認配車並鎖定。配車只代表保留，不代表實體車已移到交車地點。
不能更換配車

若已有車牌、領牌完成紀錄或任何領牌文件，系統會拒絕直接更換。請先由行政確認並處理領牌資料，避免車輛與文件對錯。

沒有可選車檢查庫存是否已進車、車型與車色是否一致、車輛是否被其他訂單保留。
08

可與配車平行

汰舊、補助與文件

  1. 勾選汰舊／政府補助。勾選後系統會立即啟用補助並開放文件上傳，不必先按儲存；新舊車主是否同人可依實況調整。
  2. 到「補助」填舊車資料。舊車車牌、舊車主資料與補助類型在這裡維護；內容異動後，畫面底部會出現儲存提示。
  3. 逐筆新增補助項目。保留類別、項目、預計金額、申請日期與狀態，系統加總補助總額；完成後按底部的「儲存補助變更」。
  4. 上傳固定文件與其他文件。其他補助文件可多筆新增、替換或刪除。
新舊車主不同

除舊車主姓名與證號外，需保存舊車主身分證正反面、舊車主存摺及新舊車主不同人聲明書。存摺資料仍需填銀行名稱、分行與帳號。

注意

汰舊與中古車回收估價不是同一件事，也不強制二選一；其他文件不列入固定文件齊全條件。交付完成後仍可繼續申請補助與補件，只有已取消訂單不能再修改補助。

09

配車後

領牌資料與文件

  1. 填實際領牌日期、領牌縣市與車牌。
  2. 上傳必備文件。新行照、新車領牌登記書與發票；有選號再上傳選號單。
  3. 其他保險單可彈性新增。
  4. 尚缺項目歸零後確認完成。完成後鎖定，不能再任意替換文件或更換配車。

系統會做什麼

  • 依實際領牌日與縣市帶入車輛結算成本。
  • 依實際領牌日帶入獎勵與補助版本。
  • 油車依排氣量級距試算領牌與強制險；電動車依品牌與輕型／重型規則帶入固定領牌規費及強制險，兩者仍可依正式單據修正。

遇到例外

  • 找不到成本：先補成本版本，不要填 0。
  • 領牌或強制險金額不同：依單據輸入並在首頁確認差額。
  • 電動車沒有金額：先確認機種已選輕型／重型，且「領牌與強制險」已有適用領牌日的版本。
  • 微型電動二輪車：目前採人工單據。
10

最後確認

交付車輛

一般客戶必須完成領牌才可交付；合作車行可先交車，再於期限內補領牌文件與收款。

  1. 先在「尾款」區塊登記收款。填實收金額、日期與方式；全數收清後勾選確認。一般訂單未收清不能交付，合作車行可先領車並由首頁持續提醒。
  2. 填交付方式與時間。託運時，時間是交給託運公司的時間。
  3. 填收車人、電話與實際地點。指定地點或託運必填目的地，託運另填公司。
  4. 快選交付車況。點選「正常」、「發現刮傷或損壞」或「其他狀況」，不必每次重新打字。
  5. 需要時補充說明。刮傷或損壞必須填損壞說明；其他狀況寫在交付備註。
  6. 完成車況、文件、鑰匙及配件贈品核對。
  7. 到表單最下方確認完成交付。完成後訂單與實體車輛會鎖定，不需重複送出。
合作車行期限從實際交車時間起，三個工作日內補領牌文件、七個工作日內補尾款；週末與系統設定的國定假日不計。
11

尚未領牌／交付

取消訂單與全額退款

  1. 展開取消流程。在訂單資料底部的「訂單取消與退款」卡片展開，填取消原因與相關說明；展開本身不會取消訂單。
  2. 系統解除配車。車輛恢復可售。
  3. 有訂金就登記全額退款。金額、日期、方式、交易資訊與證明都需保存。
  4. 退款完成才算取消完成。
系統拒絕取消

已領牌或已交付不能取消；退款金額必須等於訂金，不能少退或用分次退款結案。

12

實體庫存

快速進車、調車與車況

快速進車① 每列一台車② 可刪除錯誤列
③ 車型與車色可搜尋④ 識別號碼不可重複⑤ 出廠年月用於先進先出
取消確認整批進車

快速進車

  1. 每一列填一台車。
  2. 車型、年份與車色用下拉選擇。
  3. 填引擎／車身號碼、出廠年月與進車日。
  4. 車況說明選填。
  5. 整批確認後建立。

清單操作

  • 搜尋識別號碼、車型、車色、位置或車況。
  • 依狀態、車型、車色與位置篩選。
  • 依日期、車型、號碼、狀態排序。
  • 變更位置會自動產生調車歷程。
整批進車失敗

任一列重複、缺少資料或車色不屬於該車型時，整批都不建立。依畫面指出的列修正後再送出，避免只進一半。

先進先出機車以出廠年月判斷新舊；先確認月份，不要只看車型主檔的年份。
13

減少重複輸入

機種、售價與其他資料設定

資料維護是全公司共用的選項與規則。不要為了眼前一張訂單，直接改掉仍在生效的舊資料。

金額會同步，歷史快照不重套訂單金額異動同步應收與收清狀態，保留實收及人工調整；每筆都收清才算完成。分期／平台撥款確認後，營運實際撥款與淨利跟著收款更新；更正請改原收款。新確認可在取消時恢復先前人工金額或本單預估；舊資料無快照須人工核對。營運頁若被他人更新，請重新載入再儲存。

機種與生效版本

  • 車輛以機種、型號與年份辨識。
  • 售價與分期方案依訂單日期。
  • 成本、原廠獎勵與補助依實際領牌日期；分期額外撥款只維護在分期方案，不會混入原廠獎勵。
  • 新增未來生效版本，不回寫已完成訂單。
  • 強制險規則會直接標示年數；顏色被使用後應停用，不直接刪除。

其他設定

  • 配件與工資：售價、安裝工資與參考成本。
  • 車行獎勵品項：實物、紅包、禮券與點數的共用名稱、單位及成本版本。
  • 分期公司與方案：公司名稱、客服電話及各機種方案。
  • 車行傭金與銷售獎勵：由資料維護區直接進入，詳見下一節。
  • 車行台數獎金：品牌、能源別、指定車型與指定車行規則可累加；詳見下方「車行台數獎金」說明。
  • 工作日與假日設定：可切換年／月／日，每個帳號會記住最後的檢視。點月份進入月曆、點日期開啟單日設定，儲存後留在該日。每月同步人事行政總處資料；同步失敗保留既有日期，也能人工補登例外，週末固定不計。
  • 其他功能包含領牌與強制險、列印範本設定及舊資料 Excel 匯入。
正確例子

8/15 起同機種成本從 65,000 調為 66,000：新增 8/15 生效版本，不修改 7/1 舊版本。8/14 已領牌訂單仍保留 65,000。

佣

給合作車行／逐台給付

車行傭金與銷售獎勵

  1. 從資料維護區直接進入。選「車行傭金與銷售獎勵」，不必先進入車型編輯頁。
  2. 找到要設定的車型。「啟用中車型」與「已停用車型」分成兩個頁籤；切換時會保留搜尋條件，再依品牌、能源別及目前有無附加獎勵篩選。
  3. 按「設定傭金與獎勵」。車型由系統帶入，不需再次建立或選擇。
  4. 先建立共用獎勵品項。到「日常資料 → 車行獎勵品項」設定名稱、類型、單位及成本版本；成本異動請新增生效版本，不覆蓋舊金額。
  5. 現金與非現金分開保存。基礎傭金填每台預設現金金額；附加獎勵從共用品項選擇實物、紅包、禮券或旅遊點數，再填每台數量。系統會依方案生效日保存單位成本快照。
  6. 附加獎勵依期間留版本。新增未來版本時填生效日與結束日，不直接覆蓋仍需保留的舊方案。
不要和台數獎金混用本頁是每賣一台即適用的傭金與獎勵；必須累積達到門檻才給的金額，請到「車行台數獎金」。附加獎勵目前只保存承諾內容，尚未自動入帳或影響淨利。
手機可加入快速前往在手機「更多」按「自訂捷徑」，即可把「車行傭金與銷售獎勵」放到自己的常用位置。
獎金

給合作車行

車行台數獎金：條件、門檻與累加

  1. 在資料維護區開啟「車行台數獎金」，預設進入規則管理。這裡列出全部規則，包含未銷售及已停用規則；直接按該規則的「編輯規則」，不必先找車行。新增則按「新增規則」；名稱可自行填寫，也可留白由目前品牌與能源自動命名。
  2. 選擇適用車行、品牌、能源別與車型。品牌與車型可以搜尋並複選，未選即不限；所選品牌合併台數，例如 SYM 2 台＋SUZUKI 1 台達 3 台門檻。不同類型條件仍須同時符合。
  3. 選「按月／按季／自訂」。按月與按季可在同一年度複選，支援全選與清除，系統列出每一期完整日期；季度為 1～3、4～6、7～9、10～12 月。自訂為一段連續日期，跨年度或不同模式請另建規則。
  4. 各期間分開計算，不合併台數。例如勾 9、10 月，9 月 2 台＋10 月 1 台不能湊成 3 台。仍依實際完成領牌日期、歸屬車行逐期計算；同一期所選品牌可合計。不同月獎金／季獎金規則均達標時沿用累加，不自動展延、結算或付款。
  5. 設定共用最低台數及每台獎金，可新增／移除門檻；至少一段有效門檻。按固定儲存列的「儲存規則」後，回到規則管理。卡片分別列出適用車行、車輛條件、期間與門檻。
  6. 要核對金額時，切換試算／結算，或按規則卡片的「查看試算」。預設只列有銷售或已結算的規則，按「包含無銷售規則」可查看其餘結果。在欲處理的期間及車行按「試算明細」，核對訂單後按「確認結算本期」。其他期間須各自結算，不會一併入帳；結算或更正後回到本分頁。
  7. 任何一期已有結算，共用條件及門檻即鎖定。規則管理的「檢視規則／管理期間」仍可增減同年度未結算月份／季度，已結算期間不可取消。變更品牌、門檻或年度請另建規則，避免改到歷史結果。
名稱與適用範圍分開名稱留白時會依目前品牌與能源顯示，例如「SUZUKI 台數獎金」。適用車行另行標示，改為全部車行時不會把舊車行名存成規則名稱。自訂名稱會原樣保留；未結算規則可清空名稱改回自動命名。這不會合併規則、擴大適用範圍或重算金額。
刪除規則：先核對影響，再確認規則管理或編輯頁可按「刪除規則」。確認頁列出車行範圍、期間、門檻及目前符合條件的訂單數；勾選確認後才刪除。刪除只移除本規則及所屬設定，不刪訂單、不改既有收支，也不影響其他規則。系統保留操作人員、時間與設定快照供稽核，畫面不提供一鍵復原。若任一期已結算，只能停用；確認期間若規則被修改或結算，必須重新檢查，不能用舊確認直接刪除。
車型跟著品牌、能源篩選「指定車型」只列符合所選品牌與能源的車型；複選品牌會顯示這些品牌的車型，沒有符合結果時不會顯示其他車型。變更條件若影響已選車型，請先確認移除或按「還原品牌與能源」，再儲存。若全部移除，會明確提示將變成「不限車型」；未按儲存不會更改規則。
同規則取最高門檻，不同規則累加

A 車行達 3 台，每台 500 元，該規則即為 1,500 元，不再加低門檻金額。同一台另符合能源 300 元及車型 200 元，則該台獎金共 1,000 元。

試算不是付款，原傭金只計一次每個「規則＋期間＋車行」只能結算一次。逐單明細會標示其他獎金是試算或已結算；本次不要再輸入其他規則或原傭金。正式結算／更正才更新獎金分攤、成本及淨利，並非新增付款。更正須填原因，且保留其他規則獎金；人工覆寫傭金總額須另外核對，系統不擅自拆分。

只計歸屬合作車行的訂單；本店單須明確指定車行才計入，平台單、取消單、未完成領牌及期間外訂單不計入。收款車行及統計期間依已保存的歸屬與領牌資料，不因新增規則而更動。

通路

資料維護區

合作車行、網路平台與本店人員

三種來源各有獨立清單，不會混在同一個畫面；通路類別也從資料維護區進入。

這一台要算給另一間車行

新訂單在「訂單來源」點「這台算給其他車行」，選好後隨訂單儲存。已儲存、已交付或已完成的訂單，點明細標題旁的「調整台數歸屬」，或歸屬區塊的「變更車行」，選車行、填原因、按「儲存歸屬」；選回「原銷售車行」可恢復預設。

例如 B 的一台指定給 A：這台台數、基礎傭金與台數獎金歸 A，原銷售來源仍是 B。本店單也能指定車行，保留本店來源與承辦人，不新增基礎傭金；選「不指定車行」可取消。網路平台維持原限制。

只更新歸屬與未結算試算，不重算原車價、原傭金及其他收支，也不變更交付紀錄；台數沿用原領牌期間。獎金在正式結算後才分攤到成本與淨利。已取消或已結算的訂單不能直接調整，也不能直接加入目標車行已結算的期間。此操作不等於付款，修改人、時間、原因與前後值會保留。

合作車行

  • 啟用中與已停用分開收納；啟用中再區分有／無 LINE 群組。
  • 依縣市、行政區分組；搜尋結果仍留在同一頁，不必先猜有沒有群組。
  • 地址輸入後會判定縣市與行政區；列表篩選行政區只顯示所選縣市。列表可直接按「Google Maps 導航」規劃路線。
  • 合作關係只有「專銷」與「一般」；有排車容量一定代表合作，沒有容量仍可能合作。
  • 台鈴油車與電車的排車容量共用，不重複加總。

平台與本店人員

  • 網路平台維護來源代碼、聯絡窗口、電話、分機、手機、Email 與備註；新資料由系統配置來源代碼。
  • 本店人員維護姓名、所在店（永湛／馭盛）、電話與每筆傭金。
  • 列表的「啟用中」是快速開關；合作車行的「年節送禮」也可直接切換，畫面會留在原位。
  • 停用資料保留歷史訂單使用，但建立新訂單時不再提供選用。
輸入更快一般文字欄位會依「目前帳號＋目前欄位」顯示最近 10 筆輸入；系統已關閉瀏覽器自己產生的黑色自動完成清單。
停用與永久刪除不同

正常停止合作請使用停用，訂單與歷史資料都會保留。只有完全誤建、且沒有訂單、庫存、台數獎金或舊資料對應的車行，才能從編輯頁的「車行資料管理」輸入完整名稱後永久刪除；系統會先列出所有阻擋項目。

分發

每月車行跑訪

價格表分發

  1. 月底先確認隔月名單。每月最後一天會建立隔月清單並沿用上月的負責人與拜訪順序；新增車行會保持「未分配」，已停用負責人不會被帶入。
  2. 按「分配與排序」。先用縣市、行政區或關鍵字找出範圍；可全選目前結果後取消少數例外，也可只勾選需要的幾家。勾選後操作列會切換成批次指派模式，選擇負責人並按一次「指派給○○（N 家）」即可完成。
  3. 拖曳安排拜訪順序。分配完成後，抓住站別把手上下拖曳；每位負責人的順序分開計算，不必自行輸入號碼。只有真的調整過排序或單一家負責人時，才會出現「儲存排序與個別調整」。
  4. 確認本月分工。所有車行都指定負責人後才能確認；確認後若再次修改分工，系統會自動取消確認，提醒重新核對。
  5. 切換「我的車行／同事／未分配／全部」。不必先猜區域，自己的清單會優先依拜訪順序排列；仍可搭配完成進度、縣市、行政區或關鍵字篩選。
  6. 看品牌標記並完成分發。顯示應提供的三陽或台鈴價格表，三陽專銷會另外註記；整間車行跑完一次就按「標記完成」，不用依品牌分次完成。
  7. 外出直接聯絡、導航並留下當月備註。電話會盡量補齊區域碼供手機撥號；按「Google Maps 導航」會從目前位置規劃汽車路線，回到清單後仍可繼續勾選；需要追蹤的狀況寫在該月份備註。

沿用與歷史

  • 需要重新套用時，可在分配畫面按「沿用上月分工」。
  • 歷史月份保存當時負責人、順序、完成紀錄與備註，只供查詢。
  • 每間車行只有一位當月負責人，避免重複跑訪。

名單有誤

  • 先回合作車行修正啟用狀態、合作品牌或專銷關係。
  • 再按「重新同步本月名單」。
  • 同步不會清除已完成狀態、備註、負責人或拜訪順序。
只有台鈴電動車

這類車行不會進入價格表分發清單；如果應該出現，請先確認車行是否另有三陽或台鈴油車合作。

帳

管理者專用

建立帳號、停用人員與重設密碼

建立新同仁帳號

  1. 從「資料維護區 → 帳號與權限」進入。
  2. 填顯示名稱與登入帳號。
  3. 產生或輸入臨時密碼，保留「首次登入必須變更密碼」。
  4. 建立後立即把臨時密碼交給本人；系統不會再次顯示。

人員異動

  • 離職或暫停使用時按「停用」，不要刪除帳號。
  • 忘記密碼時由管理者重設；完成後舊裝置會被登出。
  • 管理者權限只給需要管理帳號與系統設定的人員。
  • 系統會保留誰在何時建立、修改、停用或重設。
例子

新進同仁王小明：建立帳號 wangming，產生臨時密碼並勾選首次登入變更。王小明登入後，系統會先要求設定自己的新密碼，完成才可進入首頁。

管理者離職

先確認至少還有另一個「啟用中」的系統管理者，再停用原帳號。系統會禁止停用自己或最後一位管理者，避免全公司都無法管理帳號。

每個人都能自行換密碼電腦版點上方「我的密碼」；手機版點「更多 → 變更密碼」。新密碼至少 8 碼，不強制符號或大小寫，但不能使用常見密碼或純數字。管理者看不到任何人的既有密碼。

行政／財務

營運資料與單筆淨利

訂單記錄客人買了什麼；營運資料記錄公司最後實際收到、支出及賺了多少。

實際撥款−成本−總支出＋總收入＋獎勵與傭金＝單筆淨利

完整公式：實際撥款－成本－總支出＋總收入＋實銷獎勵金＋促銷補助金＋分期補貼息＋強制險傭金＋信用卡傭金。

數字例子

實際撥款 75,000－成本 65,000－支出 2,000＋收入 1,000＋獎勵 3,000＝單筆淨利 12,000。

金額原則系統帶入的是預設或試算；正式單據、實際撥款與可人工修改欄位仍需核對。人工修改要留下原因。
不要把不確定金額都放「其他」

現金撥款通常等於車款售價；分期依期數比例試算；平台依帳本人工填。領牌、保險、選號、運費與傭金應分欄依正式單據記錄，不確定時保留單據請財務確認，避免重複計算。

Excel 平行期

歷史資料匯入

  1. 選匯入類型並上傳正式檔。系統只建立預覽，不會立即寫入。
  2. 先看處理摘要。確認可新增、已存在、人工排除、衝突、錯誤與未對應資料。
  3. 在同頁補齊主檔。未對應車型或通路可直接對應既有、快速新增，或保留為歷史文字；下次會自動沿用。
  4. 先核對來源車輛。車型不確定時展開相關資料，用車牌、車色、引擎／車身號碼、車主與日期判斷；對應彈窗也會同步顯示。
  5. 處理衝突與錯誤。比較相同識別號碼的 Excel 列，選擇修正後匯入或排除此列，並填原因。
  6. 重新驗證後再確認。問題全部處理完成，系統才開放確認匯入。
