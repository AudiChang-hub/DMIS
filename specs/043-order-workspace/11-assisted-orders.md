# 合作車行代開單與單筆查閱授權（方案 B）

## 已確認範圍

- 建立人保存實際操作者；銷售來源是實際銷售車行；佣金歸屬不授予訂單存取權。
- 內部人員於共用建立訂單的來源選「代合作車行開單」，確認所選車行公司資料。未設定完整或公司版本已變動時不得送出；成立時保存該公司快照，不依未來列印者重新推導。
- 外部帳號固定其啟用中的所屬車行，不得透過 POST 改來源或公司。接待畫面不開放內部財務。
- 本車行資料範圍包含同車行、由馭盛代開的訂單；本人範圍仍不自動擴大。admin 沿用帳號與權限／車行帳號設定範圍。
- 待接單即能依授權列印訂購單、個資同意書或合併文件；列印不代表已接單，也不變更狀態。

## 單筆例外

### 1.17.0 統一權限工作區（取代下列 1.16 舊版操作方式）

- admin 唯一管理入口為「帳號與權限 → 人員」，四頁籤為帳號資料、畫面與操作、訂單範圍、指定訂單；合作車行及訂單頁只導向此工作區。
- 指定訂單可沿用一般設定或本筆自訂。自訂時 true 為允許、false 為明確禁止；禁止優先於本人／本車行既有範圍，包含列印網址與清單／明細。查看與客戶文件列印獨立，不開放額外內部操作。
- 一般查詢／列印功能、帳號及來源啟用狀態仍為必要條件；衝突時拒絕儲存並指出要到哪個頁籤調整。admin 本人維持固定最高權限。內部人員的單筆允許不能繞過原資料範圍。
- migration 0151 僅新增 `is_override=False`，原 active/false 與勾選值不重寫，保留舊額外授權效果；管理畫面載入的是目前實際權限。admin 明確儲存自訂後才轉成 override，兩個都不勾允許儲存為全拒絕。
- 「沿用一般設定」將本筆設定停用，恢復原資料範圍，不能把此動作稱為禁止。保留版本、身分代次檢查、交易與稽核。GET 不建立 profile／授權。
- 驗證：工作區四頁、舊連結導向、非 admin GET/POST、偽造隱藏欄位、原本可列印但本筆拒絕、直接列印網址、恢復沿用、舊授權相容、上層未授權、身分變動與版本衝突；相關 PostgreSQL 交易測試與桌機／平板／手機驗收。
- 回復限制：舊版不認識明確拒絕，**啟用任何 override 後不可直接退回 1.16**，否則可能恢復已被禁止的權限。優先前向修復；必要回退須先停止對外存取、保留 DB 備份，逐筆處理拒絕及驗證後才恢復服務，不自動刪除新增欄位或回復整庫。

### 1.16 舊版相容語意（只適用尚未轉換的授權）

- admin 由訂單「查閱與列印授權」選合作車行人員；查看與列印分別勾選，須填原因，可撤銷，保留操作紀錄。
- 新增 `OrderCustomerAccessGrant`，唯一鍵為訂單＋帳號 profile。授權版本衝突或審核後身份改變時拒絕舊表單；權限變更和事件紀錄在同一交易完成。
- 單筆授權只增加客戶版清單／明細、允許的客戶附件及客戶簽署文件範圍，不增加編輯、領牌、交付、接單、財務、補助或其他列印權。
- 仍受帳號啟用、車行啟用、查詢及客戶文件列印功能權限限制。無一般查詢權但有列印權者可由已授權文件網址列印；不因此開放訂單列表。
- 撤銷額外授權不否定原本本人／本車行範圍的存取權。停用帳號不能使用；轉換身份或所屬車行會遞增 `identity_epoch`，舊授權即使轉回原車行亦不自動復活。一般功能旗標調整不改 identity epoch。
- 不更改訂單來源、建立人、佣金、金額、公司快照或已簽附件，不批次移轉舊單。

## 發布與回復

- 1.17.1 僅修正帳號總覽呈現：篩選控制項一致、建立車行帳號入口可展開並聚焦車行選單；桌機各列共用固定欄寬，平板／手機分區顯示。樣式限該頁，既有權限、啟停及資料不變；驗證相關帳號測試、不同尺寸與主題，無 migration。

- 1.16.2 僅調整身分與範圍表單文字：「全公司訂單」下方另說明僅限馭盛內部帳號授權，不限訂單來源或建立人；不修改選項值、預設範圍、既有帳號或後端權限驗證，無 migration。

- 1.16.1 僅調整客戶版訂單列表：依車主／單號、車款／規格／單純車色名稱、接單與狀態分區；搜尋與狀態保留 GET 篩選、分頁及原授權範圍。響應式與各主題驗證，不變更正式資料或權限。車色不可使用含車款名稱的 `VehicleColor.__str__` 重複拼接。

- 1.16.0，migration 0150 僅新增授權表及 profile 身份代次，既有訂單、帳號設定不變。
- 發布前 PostgreSQL 與媒體備份，完整 CI 通過後附註標籤發布。正式頁面驗證與必要的單筆授權均記錄；不以正式訂單演示代開或財務寫入。
- 優先前向修復。需回復時使用前一已驗證程式並保留新增資料表，先停用外部新增授權入口；舊版不使用新授權，不能還原整庫覆蓋發布後訂單。
