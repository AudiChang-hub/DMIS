# 報表中心統一快速分頁（A 方案）

- 範圍：來源訂單附表、人口分組附表、圖表下鑽明細（側欄／獨立頁）及彙總表。報表管理與分類設定清單不在此次範圍。
- 統一顯示第一頁、上一頁、目前／總頁數、指定頁碼與前往、下一頁、最後一頁；首末頁停用無效操作。
- 沿用全站分頁元件，擴充可指定頁碼參數與已正規化的查詢條件。既有非報表列表維持預設行為。
- 翻頁保留多選篩選、排序、圖表選取、發布版本及頁面定位。下鑽仍在側欄更新；沒有 JavaScript 時能以完整明細頁使用分頁。
- 彙總表僅切換已授權且已載入的資料列，不修改 Top N、資料統計或匯出範圍；切換每頁筆數回到第一頁。
- 頁碼輸入限整數及有效範圍，後端沿用 Paginator 越界防護。空清單不產生無效連結。
- 不更動資料庫、訂單、分類規則或報表設計。測試涵蓋查詢保留、首末頁、指定頁、無效輸入、側欄與桌機／平板／手機。
