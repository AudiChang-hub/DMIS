# 系統願景（System Vision）

## 業務背景

車行（機車經銷商）現行作業流程仰賴紙本車輛價格表、手寫訂購單、手寫報件單，以及一份共 92 個欄位的 Excel 工作表維護所有銷售與財務資料。主要場景分兩類：

1. **實體店面客戶購車**：賞車 → 詢價 → 填訂購單 → 報件 → 謄寫 Excel
2. **車行（B2B）訂購**：收件 → 報價（含傭金）→ 報件 → 謄寫 Excel

## 系統目標（依優先順序）

| # | 目標 | 說明 |
|---|---|---|
| G1 | **減少重複謄寫** | 資料從一處登打，其餘由系統自動帶出 |
| G2 | **提高資訊透明度** | 價格、傭金、牌險費率集中管理，不再翻紙本或問人 |
| G3 | **取代 Excel** | 銷售與財務資料統一由系統管理，消除冗餘欄位（如「車主名稱2」） |
| G4 | **減少紙本作業** | 報件單、訂購單由系統產出可印製的 PDF，不再手寫 |
| G5 | **發揮歷史資料價值** | 透過 BI 報表探勘銷售、財務、車行、車款的隱含價值 |

## 不在範疇（本期）

- 庫存管理（車輛進出庫）
- 多公司 / 多分店架構
- 與台鈴/山葉原廠系統 API 介接
- 客戶 APP / 線上訂購
