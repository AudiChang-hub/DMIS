# 車輛銷售管理系統｜角色快速卡

> 可單獨列印。詳細例外請看系統右上角「使用說明」。

## 業務接單快速卡

1. 首頁先搜尋姓名／電話，確認沒有重複訂單。
2. 按「＋新增」→ 來源 → 車主證件 → 車型年份車色 → 金額 → 需求。
3. 證件上傳後可先往下填；完成時回來逐欄對照照片。
4. 分期才填公司、期數、開辦費與每期金額；其他費用非必填。
5. 建立後列印訂購單兩份與個資同意書一份。
6. 需要列印身分證時，到訂單資料選「限領牌使用」或「限申請補助使用」；系統會加上用途與當日日期浮水印。
7. 看到錯誤摘要就點項目修正，不要連續按建立。

## 行政領牌／補助快速卡

1. 補助可與配車平行收件；領牌一定要先配車。
2. 補助：舊車資料 → 補助項目 → 固定文件 → 其他文件。
3. 領牌：日期／縣市／車牌 → 必備文件 → 其他保險 → 尚缺歸零 → 完成。
4. 沒有成本版本先補主檔，不填 0。
5. 完成領牌後會鎖定；不要在文件與車輛未確認前按完成。
6. 合作車行先交付時，注意 3 個工作日文件與 7 個工作日尾款提醒。

## 庫存快速卡

1. 多台車使用「快速進車」，每列一台。
2. 車型／車色下拉選；油車填引擎號碼，電車填車身號碼。
3. 出廠年月一定要核對，系統以此協助先進先出。
4. 任一列錯誤時整批不建立，修正後再送。
5. 實際位置只顯示本店或合作車行名稱；改位置會留下調車歷程。
6. 紅色「車況異常」要優先處理；一般車況說明只顯示「有備註」。

## 財務對帳快速卡

1. 統一對帳只處理分期公司、網路平台、合作車行。
2. 選待確認 → 輸入實際金額、入帳日、帳戶 → 看差額。
3. 差額不是 0 不要勾確認，先回訂單查付款與預計金額。
4. 單筆淨利以實際撥款、成本、支出、收入、獎勵與傭金計算。
5. 系統帶入仍需依正式單據核對；人工修改需留原因。
