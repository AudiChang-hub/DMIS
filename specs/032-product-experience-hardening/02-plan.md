# 032 產品體驗、安全與使用說明強化｜Plan

## Phase A：盤點與產品基線

1. 盤點現有 route、功能、文件、錯誤處理、安全設定與測試。
2. 對照零售／DMS、POS、WCAG、OWASP 與 Django 正式部署準則。
3. 建立使用者角色、任務地圖、體驗原則與成功指標。

## Phase B：共通體驗與說明

1. 建立可搜尋、可列印的任務導向幫助中心。
2. 全站加入情境式說明入口。
3. 建立錯誤摘要、欄位定位、重複送出保護與離線狀態。
4. 補齊 400／403／404／500 錯誤頁與查修編號。

## Phase C：文件與培訓

1. 取代過時 Odoo 手冊，產出目前 Django 系統 End User 手冊。
2. 建立快速上手、業務、行政、庫存、財務的任務型內容。
3. 補上例子、例外排除、安全提醒與名詞表。

## Phase D：驗證與交付

1. 自動測試、部署檢查、UI 尺寸稽核。
2. 以虛構資料執行關鍵任務。
3. 維持現有部署防護：備份、dirty tree 檢查、migration、collectstatic、服務重啟與 smoke test。

## Phase E：實際門市導入與 Excel 退場

1. 以虛構完整案例完成角色交接演練，再由 1 位業務與 1 位行政進行真實試點。
2. 建立 Excel 功能對照、正式資料來源、差異裁決人與 30 天切換節奏。
3. 每週檢視建單耗時、搜尋零結果、OCR 修正、錯誤復原與回到 Excel 的原因。
4. 至少兩位 50 歲以上人員完成放大文字、手機拍照、搜尋、錯誤修正與交班任務。
5. 通過連續 7 天不依賴 Excel 的驗收後，才將舊檔改為唯讀封存。

## 後續產品路線

- P1：角色權限、登入失敗限速、敏感文件逐次存取稽核、法人文件專區。
- P2：可用性測試儀表板、說明截圖自動更新、教育訓練模式、操作分析。
- P3：LicenseWatcher、電動車牌險規則、對外客戶入口與更完整工作流自動化。
