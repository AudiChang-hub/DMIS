# 所見即所得設計工作台（B）

## 已確認需求

- 全寬編輯工作區，精簡頂部工具列；左側報表／圖表導覽可收合，右側資料、樣式、版面、互動分頁可收合。
- 單一整頁畫布沿用正式 display 模板、結果引擎與全部圖表資源，取消單圖 iframe 與強制高度覆寫。
- 畫布尺寸與縮放分離：符合寬度、符合整頁、100% 等比例縮放，縮放不修改儲存版面。可選桌機、平板、手機目標寬度。
- 編輯模式點圖選取、拖曳排序／尺寸；互動預覽測試篩選、Ctrl 複選、提示、下鑽與匯出，不儲存資料。
- 相同設定、資料、篩選及目標尺寸下設計、預覽、正式圖表一致；舊版與草稿的差異明確區分。
- 設定提供用途、例子、範圍及不適用原因，修改後延遲刷新，保留過期／錯誤狀態與輸入；不允許舊回應覆蓋新設定。

## 架構與安全

- 保留既有 13 張報表及發布／還原機制，不自動發布或改公式；仍只有 admin 可編輯。
- 預覽透過原 admin POST 表單驗證，使用記憶體中的設定執行唯讀 display／detail／export；只允許解析到指定報表的四種查詢路由，不接受外部 URL 或任意 action。
- iframe 僅允許腳本、下載與列印對話框，無 same-origin 權限；經來源視窗及每次預覽識別碼驗證的訊息通道，才可由父頁帶 CSRF 執行查詢。
- 維持最多 8 圖、每圖 200 群與匯出 5000 筆等限制；不提供任意 JavaScript、SQL、CSS 或重啟已退役來源。
- 字級、配色、圖例、標題對齊、提示及連動是白名單設定，舊資料使用既有預設，不另建 migration。

## 驗收

- 所有既有 reader_layout 的預覽與正式版結構／樣式／資料一致；未儲存預覽不得改版本、發布內容、訂單與記憶中的閱讀頁。
- 檢查權限、CSRF、路由白名單、非法設定、過期請求、複選、下鑽、附表分頁及匯出。
- 檢查拖曳、鍵盤排序、尺寸、縮放、面板、離開提醒與草稿發布還原，桌機／平板／手機布局不溢出。
- 完整測試、提交、部署、正式健康與登入後唯讀驗收後回報；不把尺寸模擬宣稱為實體手機驗收。
