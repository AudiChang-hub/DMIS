# 首頁我的最愛與發布升版

## 1.1.1 文案修正

依使用者要求，現行首頁、設定頁、操作提示與使用說明統一稱為「常用功能」。僅修改文案，不更動資料欄位、路由、既有選擇或排序；保留已發布 1.1.0 歷程原文。新增設定頁和首頁命名回歸檢查，依 PATCH 升至 1.1.1。

## 已授權範圍

首頁常用功能改為每個帳號自己的我的最愛。沿用 UserAppearancePreference，新增 nullable JSON 與版本欄位；null 使用預設／既有手機個人捷徑，空清單表示使用者明確清空，不自動補回。手機快捷設定維持獨立，不改動既有資料。

獨立「編輯我的最愛」頁依上方導覽和資料維護子類分類，以勾選卡片、功能搜尋、僅看已選、已選預覽及上移／下移／移除調整。恢復預設、清空只改草稿，按儲存才生效；取消不寫入，未儲存離開提示。手機採單欄，不依賴拖曳。沒有 JavaScript 仍可勾選儲存。

功能清單共用現有手機捷徑定義並補上訂單、營運、工具等入口；不允許任意 URL。每次顯示與 POST 均檢查現行權限，撤權的收藏隱藏，不取得任何新授權。不提供修改他人偏好的 user_id 入口，CSRF、登入及 POST 版本衝突防護。

## 驗收與回復

測試帳號隔離、空清單、預設、順序、重複／未知／無權限項目、撤權、舊版表單衝突、CSRF、沒有 JS 的儲存、保留手機／配色偏好。前端測試搜尋、勾選、排序、重設及邊界；瀏覽器桌面／平板／手機／鍵盤／深淺色。完整 Django／PostgreSQL CI 後建立標籤、備份、部署、健康與正式功能驗證。

Migration 僅增加個人偏好欄位，無訂單／財務異動。回復舊程式時保留新增欄位和收藏資料，不反向刪除欄位。發行後修復以新版本處理。
