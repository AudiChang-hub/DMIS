# 車輛銷售管理系統｜角色快速卡

> 可單獨列印。詳細步驟與例外請看 [使用者操作手冊](USER_MANUAL.md)，或系統右上角自己的名字 → 「使用說明」。

## 業務接單快速卡

1. 先到「全部訂單」用全欄位搜尋姓名／電話，確認沒有重複訂單。
2. 按「建立訂單」，依五步驟填寫：車款與來源 → 配件與需求 → 車主與證件 → 付款與訂金 → 確認送出。
3. 每按「下一步」會存成草稿並檢查該步；有缺漏時依畫面上方提示修正，不要連續重按。
4. 證件辨識完成後逐欄對照照片，姓名、證號與地址要人工確認。
5. 分期才填分期公司、期數、開辦費與每期金額；現金單不用。
6. 建立後選簽署方式：「在行動裝置上簽名」或印紙本簽完再上傳。訂購單內容修改後要重簽。
7. 需要列印身分證時選用途（限領牌／限申請補助），系統會加用途與日期浮水印。

## 行政配車／領牌／交車快速卡

1. 配車：選單最上面是「★ 優先配車」的車，再依出廠年月由舊到新；選了別台車會提醒填原因。
2. 補助可與配車平行處理；領牌一定要先配車。
3. 領牌：填實際領牌日期、縣市、車牌 → 上傳新行照與領牌登記書（有選號再加選號單）→ 「確認領牌完成」。
4. 找不到成本規則時先補車型資料的成本版本，不填 0。
5. 交車前要符合：已配車、一般訂單已領牌、無待確認折扣、分期單已在交付區登記「已核准」、尾款收清。
6. 尾款可在交車表單一起收：「收尾款並完成交車」。
7. 合作車行先交車：3 個工作日內補領牌文件、7 個工作日內確認款項。

## 庫存快速卡

1. 多台車用「快速進車」，每列一台；全部確認後按建立。
2. 車型／車色下拉選；油車填引擎號碼，電車填車身號碼。
3. 每台選車輛來源：「公司進車」或「車行調車」（調車要填調車來源）。
4. 出廠年月一定要核對：超過 3 個月自動優先配車，未滿 3 個月可手動開啟。
5. 改實際位置會留下調車歷程；紅色「車況異常」要優先處理。
6. 已售出、已交車的車不在庫存列表；停用的車在「停用車輛」分頁。

## 財務對帳快速卡

1. 統一對帳只處理分期公司、網路平台、合作車行。
2. 選待確認 → 輸入實際金額、入帳日、帳戶 → 看差額。
3. 差額不是 0 不要勾確認，先回訂單查付款與預計金額。
4. 取消退款：可輸入沒收金額，退款＝已確認實收－沒收金額。
5. 單筆淨利以實際撥款、成本、支出、收入、獎勵與傭金計算；查看前要用自己的密碼解鎖。
6. 系統帶入仍需依正式單據核對；人工修改要留原因。
