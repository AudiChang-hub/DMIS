# 帳號體驗、淨利保護與權限一致性（B 方案）

- 已授權：訂單十欄重排；窄版機種最多 10 字元、備註 12 字元，可展開原文；姓名下保留訂單編號及多條件排序。
- 淨利採獨立明確授權（舊帳號不自動取得；admin 固定具資格），本人密碼重新驗證後目前 session 解鎖 300 秒，非滑動展延。撤權、改密碼、登出失效；解鎖失敗限流、CSRF、稽核、禁止快取；鎖定時不提供數值、淨利排序與含淨利匯出。
- 其他淨利顯示與原始財務資料入口同步防護；不改財務公式，不將所有成本／收入改成機密，人工備註無法自動保證不含敏感資訊。
- 車行帳號管理改為摘要、清單、分組表單。新增帳號手動輸入或採車行代碼＋流水號建議；仍一人一帳號，唯一性在保存時驗證，舊帳號不改名、不共用密碼。
- 首頁在主導覽第一位；建立訂單以選車為前一步，原直接建單與草稿連結相容。未授權任何子項的目錄不顯示且不得直接存取。
- 版本與說明採後端權限標記過濾，空分類不輸出；既有發布文字不覆寫，以外部權限對照標記。未知更新預設僅 admin，測試要求每個發布項目均有標記。不得以文字關鍵字猜測權限。
- 升版 1.4.0；測試授權、逾時、撤權、跨帳號與跨 session、匯出與排序、內容原始碼、多人帳號衝突、RWD、鍵盤；完整 CI、備份、標籤及正式站只讀驗收後才算完成。

## 選車追加範圍

- 車款下拉只列已上架且啟用的機種，保留品牌／能源篩選及舊 q 參數相容。
- 每種有效車色獨立圖片卡片；寬版四欄、窄版兩欄，缺圖以文字說明，選色後帶入共用訂單而非立即送出。
- admin 在選車展示管理維護每色圖片，JPEG／PNG／WebP 上限 8 MB；同車款版本鎖保護並行修改。下架及停用顏色即停止公開。
- 0138 migration 新增車行功能布林值（保留既有瀏覽能力）及車色圖片。0139 新增安全搜尋快取，從舊索引保守剔除原始財務標籤及核對 JSON，PostgreSQL 保留 trigram 索引效能。
- 不修改淨利公式／原始訂單；歷史異動中的財務核對 JSON 及 Django 緊急管理的原始財務頁面同樣需解鎖。
- 移除展示圖僅解除欄位綁定，檔案保留於既有媒體備份；不擅自下載或公開第三方車圖。回復舊程式可保留新增欄位，正式資料還原仍依既有備份流程。
