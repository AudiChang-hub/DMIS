# 全部長條圖：末端總數與彩色提示

2026/09/10 使用者確認 B：目前所有報表的水平／垂直／堆疊長條均移除分類內數字及尾端引線數字，僅保留每根長條總數。基本單系列長條的末端為該分類值。

- 共用提示框顯示分類色塊、名稱、數值、占比及總計；配色取自該圖，不另外重新分配。
- 堆疊占比以該長條總數為分母；基本長條以圖表完整範圍為分母，候選範圍另標示。不對平均、試算、零分母或負值虛構占比。
- 已顯示系列不足總數時註明未顯示系列，不冒充完整列出；小數值仍保留於提示及來源資料。
- 保留既有點選、Ctrl／⌘ 複選、月份刷選、鍵盤操作、資料與 CSV 口徑。提示可捲動並以 Escape 關閉。
- 覆蓋正式閱讀、自訂基本長條、一般堆疊及設計預覽，不改資料庫或發布設定。

驗收：純函式邊界與 DOM 安全測試、既有報表測試、完整 Django／CI；隔離與正式站檢查每根只一個末端數字、色塊與圖形一致、長清單捲動、手機邊界、連動及 PNG。測試結果於交付時回報。

## 本機驗收紀錄

- 887 項 Django 通過（SQLite 跳過 4 項資料庫專屬測試，CI 另驗 PostgreSQL），報表 101 項、前端互動 19 項通過。
- 隔離站逐頁檢查 13 個原報表、自訂報表及專用基本長條／一般堆疊：長條數與末端值數一致，SVG 無色塊內數字。
- 390×420 短畫面，20 個型號提示完整保留，PageDown 可捲至後段、Escape 關閉；提示改用支援瀏覽器的 top layer，避免被導覽列遮擋。舊瀏覽器保留原固定定位回退。
- 基本長條提示色塊等於實際 CSS 條色，人口分析提示沿用該圖配色。垂直圖快速 Ctrl 複選保留兩個分類，其他圖仍連動。
- 垂直圖 PNG 預覽成功（1346×1019），總數保留、分類內數字移除。沒有改動報表發布設定、資料或財務公式。
