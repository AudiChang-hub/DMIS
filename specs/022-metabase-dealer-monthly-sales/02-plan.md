# 實作計畫（02-plan）— Metabase 車行月銷量與累計趨勢

## 背景

- 現有 P20 dashboard 只有一張按月份與通路維度統計的圖，缺少使用者要求的「車行月銷量」與「累計銷量」組合視角。
- 目前 dashboard filter 尚未提供 `能源類型`，無法快速切分電車與油車銷售結果。

## 實作步驟

1. 新增一支專用 Metabase API 腳本，定位並更新 P20 dashboard。
2. 將既有 P20 月銷量圖改為以原始 `dealer` 欄位顯示車行名稱。
3. 將 P20 月銷量圖調整回緊湊版位，避免為了展開全部 dealer 而造成 dashboard 過長。
4. 新增一張 native SQL 折線圖，計算每個車行依月份累加的銷量。
5. 新增一張車行月銷量明細表，提供完整 dealer 清單，並以每列三組資料的矩陣版型與強化樣式提升判讀性。
6. 將 P20 dashboard 篩選器調整為 `領牌年月`、`銷售來源`、`能源類型`、`車行名稱` 四個下拉式欄位。
7. 將 `領牌年月` 預設為腳本套用時計算的最近半年（含當前月份），並將 `銷售來源` 預設為 `車行`。
8. 執行腳本套用後，透過 Metabase API 與 public dashboard 驗證圖表、明細表與篩選器可正常顯示。
