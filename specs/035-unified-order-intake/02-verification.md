# 驗收紀錄

## 本機功能驗收（2026-09-14）

- 隔離 SQLite 與合成帳號，不使用正式訂單，不送出 Google 表單。
- 車行使用共用新增頁，分期公司／24 期方案可選、金額帶入；提交後為待接單，無接單及內部財務按鈕。
- 馭盛 admin 首頁顯示待接單 1 筆，實際接單後保存 admin 與接單時間；新表單預設來源馭盛。
- 桌面 1440、平板 820、手機 390 像素無全頁橫向溢出；接單勾選獨立成區，避免固定底列擁擠。鍵盤可移至建立按鈕。
- 新增接單／隔離／附件／預設初始化測試 18 項，本機通過 17 項；PostgreSQL 接單競爭測試由 CI 執行。
- 相關回歸 63 項通過（2 項環境限定略過），前端分期與表頭 8 項通過。
- 完整回歸第一輪 1094 項，發現庫存測試資料缺門市、訂金初值改變兩處；已修正並單獨重跑通過。完整修訂版以 CI 為發布閘門。
- 檢查版本為 1.2.0、既有版本紀錄不變；Django check 與 migration 一致性通過。

## 正式發布檢核

完整 CI（含 PostgreSQL 接單競爭）、已發布 tag、T470P 備份與部署、公開健康檢查及登入後只讀功能核對均須通過。未通過前不可視為正式交付。

## 使用與維運邊界

- 「資料維護區 → 帳號與權限 → 下單身分／所屬通路」由 admin 設定。新建立帳號須先確認身分，再交付外部使用。
- 車行綁定後可看該車行既有訂單的精簡進度；不能看他行、內部財務或其他人的草稿。帳號停用仍沿用既有登入安全機制。
- 接單提醒為首頁及列表查詢，重新整理取得最新狀態；不包含 Email／LINE／推播。
- 原 Google Sites／Forms 保持不變，尚未將其入口切換到系統。
- migration 保留舊單狀態；admin 預設綁定只補缺少的設定，不改既有帳號角色或來源資料。
- 附件限制為分期表 1 個、補充檔案 10 個，每個 20 MB、同次含證件合計 35 MB（正式代理上限 40 MB）；相同內容重複暫存會去重，刪除於資料庫提交後清理檔案。
- 待接單已投入使用後，回退不得直接部署不識別該狀態的舊版；應保留欄位與檔案並以前向修正處理。
