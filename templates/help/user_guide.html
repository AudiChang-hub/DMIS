01

第一次使用

三分鐘認識系統

先記住四件事：首頁看待辦、任何內容都能搜尋、訂單建立後才配實體車、資料有問題不要重複建單。

車輛銷售管理① 使用說明② 檢查更新
③ 戰情首頁④ 全欄位搜尋⑤ 今天的待辦與最近訂單
首頁訂單＋新增營運資料
  1. 登入後先看戰情首頁。優先處理、待配車、進行中與庫存數量都會集中顯示。
  2. 要找資料就直接搜尋。像 Excel 的尋找，不必先選姓名、電話或車牌欄位。
  3. 客人在面前就按「＋新增」。依來源、車主、車輛、金額、需求五區填寫，輸入中會自動保存草稿。
  4. 工作做完才按完成。配車、領牌、交付等完成後會鎖定，避免後續誤改。
手機加到主畫面後看不到新版？先按上方「檢查更新」，確認草稿或修改已儲存，再按「重新載入」。
02

每天第一站

戰情首頁與 Excel 式搜尋

怎麼找

  • 輸入 0912 找電話片段。
  • 輸入 ABC1234 或 ABC-1234 找車牌。
  • 輸入姓名、車型、配件、備註或文件名稱。
  • 搜尋結果會標示「哪個欄位、哪段內容」符合。

怎麼看

  • 「優先處理」是逾期或重大待辦。
  • 「待配車」是訂單成立但未指定實體車。
  • 「進行中」是配車後至交付完成前。
  • 本月成果以實際領牌日期認列，不是訂單建立日。
例子

只記得客人姓「張」且買灰色 SUI 125：先搜「張」，再從結果顯示的車型／車色辨認，不必翻每一張訂單。

搜尋不到

改用部分內容、移除空格或連字號；「最近訂單」只顯示最新資料，要看全部請進「全部訂單」。

03

全部訂單

依狀態查看與繼續處理

  1. 從上方「全部訂單」或手機「訂單」進入。
  2. 選擇待配車、領牌、交付、取消等狀態。只縮小清單，不會改變訂單。
  3. 點訂單列進入工作頁籤。先看狀態、尚缺項目與處理紀錄。
避免重複訂單找不到訂單時，先回首頁用姓名、電話、證號或車牌做全欄位搜尋，再決定是否建立。
04

客人在面前

建立訂單與自動草稿

1來源→2車主→3車輛→4金額→5需求
  1. 來源。本店不需再選名稱；合作車行或網路平台要選正確來源。找不到時先請管理者新增，不要亂選。
  2. 車主與證件。本國自然人、外籍／居留者上傳正反面；法人由人員自行填公司基本資料。
  3. 車輛。選品牌車型、年份與車色。此時不選引擎／車身號碼，建立後才配車。
  4. 金額。選現金、分期或刷卡；分期才會出現公司、期數、開辦費與每期金額。其他費用不是必填。
  5. 需求。選號方式與交車方式必填；配件、汰舊／補助依實際需要填寫。
完整例子

陳小華在本店買 SUZUKI SUI 125／2026／白，現金付款、不申請補助、來店取車：來源選本店；完成證件核對；選車型車色；付款選現金；牌險依單據；交車選來店取車，再按「建立訂單」。

外籍與法人外籍／居留者不需登記護照。法人由人員自行填基本資料；領牌前準備登記證明、核准函、近一期 401、公司大小章，申請補助另備公司存摺。沒有專屬名稱的資料放到對應工作的「其他文件」並清楚命名。

草稿

開始輸入後會自動保存。新建單與重新開啟草稿都能看到「刪除草稿」。刪除會連草稿照片一起移除，無法復原。

正式修改

訂單建立後的修改不會自動保存，必須填變更原因並按「儲存修改」。不想保留就按「取消修改」。

05

證件核對

拍照、OCR 與人工確認

證件正面照片查看・更換・移除
對照
姓名・生日・證號逐字核對後確認
證件反面照片查看・更換・移除
對照
戶籍／居留地址留意巷、弄、樓、房
  1. 選「拍照」或「上傳圖片」。避免反光、模糊、裁切及過斜。
  2. 看到「正在辨識」後可先填其他區塊。不要重複上傳同一張。
  3. 完成後回到車主區逐欄對照。OCR 只是協助輸入，照片才是核對依據。
  4. 有錯就直接修正，再勾人工核對。

文件差異

  • 本國自然人：姓名、生日、證號在正面，地址在反面。
  • 外籍／居留者：主要資料多在正面，但正反面仍都要保存。
  • 法人：系統會提示自行填寫基本資料，不做證件 OCR。

常見辨識錯誤

  • 姓名少一字：看正面照片補齊。
  • 「10樓」變「1樓」：放大反面逐字核對。
  • 正反面放錯：移除後重新上傳。
  • 失敗：重新拍攝，或人工輸入後核對。
06

訂單建立後

工作頁籤不是關卡

訂單建立
配車 → 領牌 → 交付補助資料與文件（可同步）簽署文件在訂單資料內隨時補上

上方頁籤是不同工作區，不必依序全部通過。補助可在還沒配車時先收件；簽署文件不是獨立階段，回到「訂單資料」即可上傳。一般客戶仍須先配車、完成領牌，才可交付。

看「建議下一步」系統會依目前資料提出一項主要建議，並列出最多兩項可同步工作。人在其他頁籤時可點按前往；已位於建議頁籤時會標示「目前作業」，不再顯示重複的前往按鈕。這是操作指引，不會自動替你配車或送出資料。

不想現在處理

  • 按「稍後處理」會縮成一列，不會消失。
  • 按縮小列的「查看」可立即展開。
  • 完成一個階段後，系統會依新狀態顯示新的建議。

例外情況

  • 沒有可售車：引導到快速進車。
  • 合作車行先領車：持續提醒三個工作日內補領牌文件。
  • 取消待退款、逾期文件與收款會優先顯示。
角色交接

業務完成訂單與證件核對 → 行政／庫存完成配車，補助可同步收件 → 行政完成領牌 → 交付人員核對車況與收款 → 財務確認撥款與單筆淨利。每次接手都先看尚缺項目與處理紀錄，不用 LINE 訊息代替系統紀錄。

07

內部協調

配車與更換配車

  1. 進入「配車」。清單只顯示符合車型與車色且可售的車。
  2. 核對識別號碼與實際位置。油車是引擎號碼；電動車／微型電動車是車身號碼。
  3. 按確認配車並鎖定。配車只代表保留，不代表實體車已移到交車地點。
不能更換配車

若已有車牌、領牌完成紀錄或任何領牌文件，系統會拒絕直接更換。請先由行政確認並處理領牌資料，避免車輛與文件對錯。

沒有可選車檢查庫存是否已進車、車型與車色是否一致、車輛是否被其他訂單保留。
08

可與配車平行

汰舊、補助與文件

  1. 勾選汰舊／政府補助。勾選後系統會立即啟用補助並開放文件上傳，不必先按儲存；新舊車主是否同人可依實況調整。
  2. 到「補助」填舊車資料。舊車車牌、舊車主資料與補助類型在這裡維護；內容異動後，畫面底部會出現儲存提示。
  3. 逐筆新增補助項目。保留類別、項目、預計金額、申請日期與狀態，系統加總補助總額；完成後按底部的「儲存補助變更」。
  4. 上傳固定文件與其他文件。其他補助文件可多筆新增、替換或刪除。
新舊車主不同

除舊車主姓名與證號外，需保存舊車主身分證正反面、舊車主存摺及新舊車主不同人聲明書。存摺資料仍需填銀行名稱、分行與帳號。

注意

汰舊與中古車回收估價不是同一件事，也不強制二選一；其他文件不列入固定文件齊全條件。交付完成後仍可繼續申請補助與補件，只有已取消訂單不能再修改補助。

09

配車後

領牌資料與文件

  1. 填實際領牌日期、領牌縣市與車牌。
  2. 上傳必備文件。新行照、新車領牌登記書與發票；有選號再上傳選號單。
  3. 其他保險單可彈性新增。
  4. 尚缺項目歸零後確認完成。完成後鎖定，不能再任意替換文件或更換配車。

系統會做什麼

  • 依實際領牌日與縣市帶入代銷結算成本。
  • 依實際領牌日帶入獎勵與補助版本。
  • 油車依級距試算牌險，仍可依正式單據修正。

遇到例外

  • 找不到成本：先補成本版本，不要填 0。
  • 牌險不同：依單據輸入並在首頁確認差額。
  • 電動／微型電動：公式未完整時採人工單據。
10

最後確認

交付車輛

一般客戶必須完成領牌才可交付；合作車行可先交車，再於期限內補領牌文件與收款。

  1. 先在「尾款」區塊登記收款。填實收金額、日期與方式；全數收清後勾選確認。一般訂單未收清不能交付，合作車行可先領車並由首頁持續提醒。
  2. 填交付方式與時間。託運時，時間是交給託運公司的時間。
  3. 填收車人、電話與實際地點。指定地點或託運必填目的地，託運另填公司。
  4. 快選交付車況。點選「正常」、「發現刮傷或損壞」或「其他狀況」，不必每次重新打字。
  5. 需要時補充說明。刮傷或損壞必須填損壞說明；其他狀況寫在交付備註。
  6. 完成車況、文件、鑰匙及配件贈品核對。
  7. 到表單最下方確認完成交付。完成後訂單與實體車輛會鎖定，不需重複送出。
合作車行期限從實際交車時間起，三個工作日內補領牌文件、七個工作日內補尾款；週末與系統設定的國定假日不計。
11

尚未領牌／交付

取消訂單與全額退款

  1. 展開取消訂單。填取消原因與相關說明。
  2. 系統解除配車。車輛恢復可售。
  3. 有訂金就登記全額退款。金額、日期、方式、交易資訊與證明都需保存。
  4. 退款完成才算取消完成。
系統拒絕取消

已領牌或已交付不能取消；退款金額必須等於訂金，不能少退或用分次退款結案。

12

實體庫存

快速進車、調車與車況

快速進車① 每列一台車② 可刪除錯誤列
③ 車型與車色可搜尋④ 識別號碼不可重複⑤ 出廠年月用於先進先出
取消確認整批進車

快速進車

  1. 每一列填一台車。
  2. 車型、年份與車色用下拉選擇。
  3. 填引擎／車身號碼、出廠年月與進車日。
  4. 車況說明選填。
  5. 整批確認後建立。

清單操作

  • 搜尋識別號碼、車型、車色、位置或車況。
  • 依狀態、車型、車色與位置篩選。
  • 依日期、車型、號碼、狀態排序。
  • 變更位置會自動產生調車歷程。
整批進車失敗

任一列重複、缺少資料或車色不屬於該車型時，整批都不建立。依畫面指出的列修正後再送出，避免只進一半。

先進先出機車以出廠年月判斷新舊；先確認月份，不要只看車型主檔的年份。
13

減少重複輸入

客戶、車型與其他資料維護

資料維護是全公司共用的選項與規則。不要為了眼前一張訂單，直接改掉仍在生效的舊資料。

車型與生效版本

  • 售價與分期方案依訂單日期。
  • 成本、獎勵與傭金依實際領牌日期。
  • 新增未來生效版本，不回寫已完成訂單。
  • 顏色被使用後應停用，不直接刪除。

其他主檔

  • 配件：售價、工資與參考成本。
  • 合作通路：車行／平台、聯絡窗口與品牌傭金。
  • 年節送禮：查看名單後可直接返回全部資料；需增減多家時使用「管理送禮名單」批次儲存。
  • 分期公司：名稱與客服電話。
  • 工作日曆、品牌牌險、台數獎金與列印套表。
正確例子

8/15 起同車型成本從 65,000 調為 66,000：新增 8/15 生效版本，不修改 7/1 舊版本。8/14 已領牌訂單仍保留 65,000。

14

行政／財務

營運資料與單筆淨利

訂單記錄客人買了什麼；營運資料記錄公司最後實際收到、支出及賺了多少。

實際撥款−成本−總支出＋總收入＋獎勵與傭金＝單筆淨利

完整公式：實際撥款－成本－總支出＋總收入＋實銷獎勵金＋促銷補助金＋分期補貼息＋強制險傭金＋信用卡傭金。

數字例子

實際撥款 75,000－成本 65,000－支出 2,000＋收入 1,000＋獎勵 3,000＝單筆淨利 12,000。

金額原則系統帶入的是預設或試算；正式單據、實際撥款與可人工修改欄位仍需核對。人工修改要留下原因。
不要把不確定金額都放「其他」

現金撥款通常等於車款售價；分期依期數比例試算；平台依帳本人工填。領牌、保險、選號、運費與傭金應分欄依正式單據記錄，不確定時保留單據請財務確認，避免重複計算。

15

統一處理

分期、平台與車行撥款對帳

訂單／車主① 對帳公司或車行
② 預計金額③ 填實際金額④ 差額會立即辨識
⑤ 入帳日與帳戶確認後儲存
  1. 選對帳對象與「待確認」。
  2. 依對方帳本填實際金額與入帳日。可補收款帳戶。
  3. 看預計、實際與差額。
  4. 差額正確才勾確認並儲存。
差額不是 0

先不要確認。回訂單核對付款方式、分期期數、平台／車行與預計金額；本頁只核對實際有沒有撥款與金額是否正確，不需處理批次總額。

16

Excel 平行期

歷史資料匯入

  1. 選匯入類型並上傳正式檔。系統只建立預覽，不會立即寫入。
  2. 先看處理摘要。確認可新增、已存在、人工排除、衝突、錯誤與未對應資料。
  3. 在同頁補齊主檔。未對應車型或通路可直接對應既有、快速新增，或保留為歷史文字；下次會自動沿用。
  4. 處理衝突與錯誤。比較相同識別號碼的 Excel 列，選擇修正後匯入或排除此列，並填原因。
  5. 重新驗證後再確認。問題全部處理完成，系統才開放確認匯入。
  6. 原始檔保持不變。人工修正只作用於本次匯入暫存值，並保留處理人與時間。
同一台車後來賣中古車兩筆都保留，把後續交易的車輛類別確認為「中古車」；系統不會再次扣新車庫存。
這次檔案不想匯入待確認或處理失敗的批次可直接刪除；正式資料不會受影響。
已經完成匯入只能封存紀錄，不能直接刪除已建立的訂單與庫存。
第一次正式匯入

請由管理者陪同。Excel 少一列不代表要刪除系統資料；不要為了通過預覽而任意改車牌、證號或識別號碼。

紙本作業

訂單文件

  • 建立訂單後可一次列印三頁：訂購單兩份、個資同意書一份。

信封／報件單

  • 在列印套表建立新版。
  • 背景可用 Excel、PDF 或圖片；信封可無背景。
  • 用最近訂單預覽位置，再調 X、Y 與印表機偏移。

安全

每個人都要遵守

個資、帳號與敏感資料

  • 每人使用自己的帳號，不共用；變更紀錄才知道是誰操作。
  • 密碼連續錯誤 5 次會暫停嘗試 15 分鐘；不要一直重按登入。
  • 公用電腦或手機使用完畢要登出；裝置遺失立即通知管理者。
  • OCR 完成仍要人工核對，不把證件照片貼到 LINE 群組當作系統歸檔。
  • 下載到手機的證件與存摺，送件完成後刪除本機副本。
  • 車控與電池密碼只填專用欄位，不抄到備註；每次查看都應有正當作業目的。
  • 發現不認識的操作人、異常變更或不該看到的資料，立即停止操作並回報。
系統目前的權限僅限內部成員且多數功能權限相同；這不代表可查看或修改與工作無關的個資。
