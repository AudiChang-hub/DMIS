選車入口與車行帳號

  1. admin 在「資料維護區 → 機種與售價」編輯年式，切到上方「選車圖片與介紹」分頁，上傳有權使用的圖片、填寫介紹。上架跟著機種啟用狀態：在機種與售價勾「啟用中」就自動上架，取消勾選就自動下架，這裡不用另外設定。售價、規格與分期沿用機種設定；未上架或停用不公開。
  2. 「合作車行 → 登入帳號」按「＋ 新增人員帳號」，或在「帳號與權限」按「＋ 建立車行帳號」選車行。帳號自動綁定該車行；「編輯帳號與功能」「重設密碼」會帶到帳號與權限的人員工作區，停用請在「帳號資料」取消「帳號啟用中」。
  3. 車行帳號預設可選車、查詢與下單、列印客戶文件，訂單範圍預設為「本人建立的訂單」；要看同車行其他人的單請改為「所屬車行的訂單」。另有「下單金額調整」「可贈送配件」可個別開放。取消「可建立訂單與使用自己的草稿」後為唯讀進度。只有 admin 可調整。
  4. 選車頁不登入也能瀏覽，可分享給客人或車行。選好車色與付款方式後按「登入並接續填單」，選擇會帶入訂單；送出後為待接單，馭盛接單後可看到人員與時間。
  5. 首次登入需更換臨時密碼；不建議多人共用同一帳號。停用保留歷史紀錄。

展示管理篩選與啟用車色

各車色與進階主圖選檔後即時預覽並標示「尚未儲存」；按「儲存展示設定」才上傳。「取消此次圖片變更」恢復原圖。支援 JPEG、PNG、WebP，每張最多 8 MB；格式、大小或圖片讀取有誤時請重選或取消變更。

編輯頁每個啟用車色各有圖片預覽、上傳及移除；不選新檔會保留原圖，停用色的照片不會刪除。未上架圖片只有 admin 能預覽。主圖對應收在「車款主圖與既有圖片對應（進階）」。若編輯途中被停用或其他人已更新，請重新整理再操作。

「資料維護區 → 原廠車型比對」可讀取 SYM／SUZUKI 官網，分「待對應」「有變動」「可補圖」處理；系統每週一自動檢查並通知 admin，售價只提醒不自動修改。

新版首頁、營運總表、排序與狀態

  • 首頁按「編輯常用功能」，依分類勾選或搜尋功能。在首頁顯示預覽中上移、下移、移除；恢復預設或清空只改本次草稿，按「儲存常用功能」才生效。取消不儲存。同帳號跨裝置共用，不影響其他人或手機快速前往；沒有權限的項目不會出現。未設定時預設為全部訂單、建立訂單、營運總表、報表中心、使用說明。另一視窗已更新時會提醒並載入最新設定，確認後再存。
  • 首頁「公告與更新」分「系統公告與最新消息」「版本歷程」兩頁；版本歷程只列最近兩版，顯示版號、發布時間（台北）及新增／改善／修正內容，點擊版本可展開或收合，按「查看完整版本歷程」看全部。「正式編版前更新紀錄」標示提交日期。一般帳號只看到與自己功能有關的項目。
  • 營運總表看近 12 個月走勢、收款風險與作業卡點；全部訂單負責查單及逐筆收支；報表中心做車型、通路分析。
  • 本月新成立訂單依成立日期，其餘成交成果依領牌日截至今日。與上月同期比較，月底比較完整月份；上月為零顯示無比較基準。
  • 車款成交額是車款售價合計，不是實際收款。訂單淨利未含公司租金、薪資等全公司費用。待補成本或待核對資料不計入淨利；圖表斷線／破折號代表缺資料，不是零獲利。
  • 收款風險涵蓋所有月份目前未結事項：待收款按應收大於已收；已有收款待確認按實收已登記但營運收款未確認。兩類可能重疊。點指標下方連結查看明細，仍受原畫面權限限制。
  • 訂單表頭直接點擊追加排序，再點切換方向。排序條件列可逐項「移除」「提前」「延後」；「全部清除」才會移除全部。日期顯示新→舊／舊→新，金額大→小／小→大，文字採系統正序／反序。
  • 領牌日期排第一順位時，遞減會把未領牌置前，遞增置後；排序後回第一頁，保留搜尋及篩選。
  • 狀態以標籤文字為準，顏色只是輔助；已取消／已退款的標籤帶 × 符號，取消待退款與補件提醒以紅色系提示。自家車行來源顯示馭盛。
  • 取消／已退款與取消待退款不計成交淨利；缺日期顯示「—」，不再催補領牌日。既有日期、收款、退款、費用與異動紀錄仍保留；取消待退款仍須完成退款。
  • 右上角自己的名字 →「外觀配色」可選墨黑群青、夜間深墨、跟隨裝置、高對比等；顏色不取代文字，鍵盤焦點有外框，停用按鈕仍可辨識。

系統公告管理（僅 admin）

  1. 從「資料維護區 → 系統公告管理」或首頁「管理系統公告」進入。
  2. 填標題、純文字內容、置頂、顯示對象（所有人員、店內人員、合作車行人員、指定人員、指定合作車行）與台北時間起訖；結束時間可留白。可加圖片（JPEG／PNG／WebP，每張 8 MB、每則 8 張）與附件（每份 20 MB）。

依狀態查看與繼續處理

  1. 從上方「全部訂單」（依帳號範圍可能顯示為「本車行訂單」或「我的訂單」）進入，手機底部同名按鈕。

04

客人在面前

建立訂單與自動草稿

1車款與來源→2配件與需求→3車主與證件→4付款與訂金→5確認送出
  1. 車款與來源。從選車頁帶入車型與車色，不選引擎／車身號碼；接單後才配車。來源選本店、合作車行或網路平台，合作車行帳號固定所屬車行；找不到來源時先請管理者新增，不要亂選。
  2. 配件與需求。加購配件計入應收、贈送不計；選號方式與交車方式必填，送至指定地點或託運要填目的地。
  3. 車主與證件。自然人上傳證件正反面，辨識完成並核對後才能按下一步；法人自行填公司資料。
  4. 付款與訂金。選現金、分期或刷卡；分期選公司與期數後按「套用選取方案」。訂金：現金填實付金額，分期預設以加購配件金額。
  5. 確認送出。逐段核對摘要，需要時按「修改」；按「確認並建立訂單」。每按「下一步」都會存草稿並檢查該步。
完整例子

在馭盛購車，先選車型車色，來源選馭盛；依五個步驟完成配件與交車方式、證件核對與付款，最後在確認頁按「確認並建立訂單」。店內人員可勾「由我接單」，否則新單會進待接單，尚不可配車。

建立後立即簽署訂單成立後會問「這次要怎麼簽？」：在行動裝置上簽名，或印出紙本簽完上傳。之後也可在訂單的「列印與簽署文件」步驟處理。
店內與車行共用流程車行帳號固定所屬車行，分期從車型方案選取，不能修改店內售價、收款或其他財務。需求寫在備註，分期表及補充檔案可隨草稿保存；送出後由店內協助修正。

有人接單了嗎？

首頁「待接單工作」顯示筆數，點入可查看清單；尚未接單的訂單不能配車。店內開啟訂單按「由我接單」，會保存接單人與時間；車行在訂單進度看到相同資訊。重新整理可取得最新狀態。

admin 如何指定帳號？

資料維護區 → 帳號與權限 → 該人員「訂單範圍」的下單身分與「預設店別／所屬車行」。admin 為馭盛店內管理帳號；合作車行必須綁定車行。畫面權限中的「訂單內部財務編輯」控制店內財務表單修改，接單權限屬於訂單作業。車行不因勾選內部畫面而取得公司資料。

外籍與法人外籍／居留者不需登記護照。法人由人員自行填基本資料；領牌前準備登記證明、核准函、近一期 401、公司大小章，申請補助另備公司存摺。沒有專屬名稱的資料放到對應工作的「其他文件」並清楚命名。

草稿

開始輸入後會自動保存；從「我的接待草稿」按「繼續本筆下單」，會回到尚未完成的步驟。新建單與重新開啟草稿都能看到「刪除草稿」。刪除會連草稿照片一起移除，無法復原。

減少重複輸入

機種、售價與其他資料設定

資料維護是全公司共用的選項與規則。不要為了眼前一張訂單，直接改掉仍在生效的舊資料。

金額會同步，歷史快照不重套訂單金額異動同步應收與收清狀態，保留實收及人工調整；每筆都收清才算完成。分期／平台撥款確認後，營運實際撥款與淨利跟著收款更新；更正請改原收款。新確認可在取消時恢復先前人工金額或本單預估；舊資料無快照須人工核對。營運頁若被他人更新，請重新載入再儲存。

機種與生效版本

  • 車輛以機種、型號與年份辨識。
  • 售價與分期方案依訂單日期。
  • 成本、原廠獎勵與補助依實際領牌日期；分期額外撥款只維護在分期方案，不會混入原廠獎勵。
  • 售價版本：分期帶「建議售價」，現金帶「現金價」，只填一個時兩者都用它。沒有有效售價時，沒有調價授權的人無法送出訂單。
  • 新增未來生效版本，不回寫已完成訂單。
  • 強制險規則會直接標示年數；顏色被使用後應停用，不直接刪除。

其他設定

  • 配件與工資：售價、安裝工資與參考成本。
  • 車行獎勵品項：實物、紅包、禮券與點數的共用名稱、單位及成本版本。
  • 分期公司與方案：公司名稱、客服電話及各機種方案。
  • 車行傭金與銷售獎勵：由資料維護區直接進入，詳見下一節。
  • 車行台數獎金：品牌、能源別、指定車型與指定車行規則可累加；詳見下方「車行台數獎金」說明。
  • 工作日與假日設定：可切換年／月／日，每個帳號會記住最後的檢視。點月份進入月曆、點日期開啟單日設定，儲存後留在該日。每月同步人事行政總處資料；同步失敗保留既有日期，也能人工補登例外，週末固定不計。
  • 車輛品牌：新增機種前要先建立品牌，機種與牌險規則的品牌都從這裡選。
  • 領牌與強制險：計算方式有公式計算、固定整包金額、固定分項金額、人工輸入；電動車沒有適用規則時無法試算。
  • 其他功能包含列印範本設定及舊資料 Excel 匯入。

獎金

給合作車行

車行台數獎金：條件、門檻與累加

  1. 在資料維護區開啟「車行台數獎金」，預設進入規則管理。這裡列出全部規則，包含未銷售及已停用規則；直接按該規則的「編輯規則」，不必先找車行。新增則按「新增規則」；名稱可自行填寫，也可留白由目前品牌與能源自動命名。
  2. 選擇適用車行、品牌、能源別與車型。品牌與車型可以搜尋並複選，未選即不限；所選品牌合併台數，例如 SYM 2 台＋SUZUKI 1 台達 3 台門檻。不同類型條件仍須同時符合。
  3. 選「按月／按季／自訂」。按月與按季可在同一年度複選，支援全選與清除，系統列出每一期完整日期；季度為 1～3、4～6、7～9、10～12 月。自訂為一段連續日期，跨年度或不同模式請另建規則。
  4. 各期間分開計算，不合併台數。例如勾 9、10 月，9 月 2 台＋10 月 1 台不能湊成 3 台。仍依實際完成領牌日期、歸屬車行逐期計算；同一期所選品牌可合計。不同月獎金／季獎金規則均達標時沿用累加，不自動展延、結算或付款。
  5. 設定共用最低台數及每台獎金，可新增／移除門檻；至少一段有效門檻。按固定儲存列的「儲存規則」後，回到規則管理。卡片分別列出適用車行、車輛條件、期間與門檻。
  6. 要核對金額時，切換試算／結算，或按規則卡片的「查看試算」。預設只列有銷售或已結算的規則，按「包含無銷售規則」可查看其餘結果。在欲處理的期間及車行按「試算明細」，核對訂單後按「確認結算本期」。其他期間須各自結算，不會一併入帳；結算或更正後回到本分頁。
  7. 任何一期已有結算，共用條件及門檻即鎖定。規則管理的「檢視規則／管理期間」仍可增減同年度未結算月份／季度，已結算期間不可取消。變更品牌、門檻或年度請另建規則，避免改到歷史結果。
名稱與適用範圍分開名稱留白時會依目前品牌與能源顯示，例如「SUZUKI 台數獎金」。適用車行另行標示，改為全部車行時不會把舊車行名存成規則名稱。自訂名稱會原樣保留；未結算規則可清空名稱改回自動命名。這不會合併規則、擴大適用範圍或重算金額。
刪除規則：先核對影響，再確認規則管理或編輯頁可按「刪除規則」。確認頁列出車行範圍、期間、門檻及目前符合條件的訂單數；勾選確認後才刪除。刪除只移除本規則及所屬設定，不刪訂單、不改既有收支，也不影響其他規則。系統保留操作人員、時間與設定快照供稽核，畫面不提供一鍵復原。若任一期已結算，只能停用；確認期間若規則被修改或結算，必須重新檢查，不能用舊確認直接刪除。
車型跟著品牌、能源篩選「指定車型」只列符合所選品牌與能源的車型；複選品牌會顯示這些品牌的車型，沒有符合結果時不會顯示其他車型。變更條件若影響已選車型，請先確認移除或按「還原品牌與能源」，再儲存。若全部移除，會明確提示將變成「不限車型」；未按儲存不會更改規則。

行政／財務

營運資料與單筆淨利

訂單記錄客人買了什麼；營運資料記錄公司最後實際收到、支出及賺了多少。

實際撥款−成本−總支出＋總收入＋獎勵與傭金＝單筆淨利

完整公式：實際撥款－成本－總支出＋總收入＋實銷獎勵金＋促銷補助金＋分期補貼息＋強制險傭金＋信用卡傭金。促銷補助金只有網路平台訂單會自動帶入，其他來源帶 0，必要時由財務人工更正。

數字例子

實際撥款 75,000－成本 65,000－支出 2,000＋收入 1,000＋獎勵 3,000＝單筆淨利 12,000。

金額原則系統帶入的是預設或試算；正式單據、實際撥款與可人工修改欄位仍需核對。人工修改要留下原因。
不要把不確定金額都放「其他」

現金撥款通常等於車款售價；分期依方案設定的預估撥款（按比例試算、固定金額或本單另填）；平台依帳本人工填。領牌、保險、選號、運費與傭金應分欄依正式單據記錄，不確定時保留單據請財務確認，避免重複計算。

在哪裡填訂單明細的「收入與支出」步驟；成本、獎勵與傭金在「進階：成本、獎勵與傭金」。找不到結算成本時會顯示「沒有符合領牌日期的版本」，請先補成本版本，不要填 0。本店不記錄發票。

  2. 設定圖表與頁面位置。每份最多 8 張，支援長條、堆疊長條、折線、圓環占比、資料表及指標卡。堆疊圖另選不同的細分系列，例如按月份細分銷售通路；只支援可相加的台數或非負車價合計。可指向區塊查看數字、點擊查看該區塊訂單，也可展開「細分數字」操作。圓環只能用台數或非負車價合計，占比以完整範圍計算，Top N 未顯示部分保留灰色，平均與試算不可使用圓環。可選側欄分類與順序；每份已發布報表就是一個可切換頁面，私人頁不會出現在其他帳號的側欄。
  3. 年、月、日與未填日期。讀者可用「日期圖表層級」切換按年、月或日，非日期分類的圖表不受影響，明細與 CSV 沿用同一層級。預設以領牌日期統計時不含未領牌訂單；admin 可明確勾選未選期間時納入，這些訂單會另列「日期未填寫」，不歸入任何月份。指定日期範圍或月份後仍排除未填日期，不影響訂單或財務的計算口徑。
  4. 系列太多與舊分類比對。堆疊圖可設定系列上限，依畫面顯示主分類中的合計排名；可將其餘合併為「其他系列」並下鑽，或不顯示但保留完整總數。CSV 會註明是否略去其餘系列。「舊報表車種分類（比對用）」沿用原 MotorType 公式的整段文字匹配，歷史訂單讀取匯入型號，新訂單使用 DMIS 型號；型號額外字尾可能歸入其他，不等於機種或能源別，也不修改傭金及獎金。
  5. 傭金使用 DMIS 的保存結果。指標選「DMIS 車行傭金支出」，可按台數與傭金歸屬車行分類並追查來源訂單。這是收支保存金額，可能含已分配獎金，不代表已付款，也不再加一次原報表台數獎金。若有訂單缺少收支資料，合計顯示「待補收支資料」，不能當作零元。實物方案不等於已發放紀錄，目前不混入此金額。
  6. 固定範圍與讀者篩選分開。在「這份報表固定統計哪些訂單？」複選品牌、能源、來源類型、車行／平台或指定車型；未勾選表示不限。單張圖表可展開「此圖額外固定條件」，例如同頁分別看油車與電動車。報表固定條件、單圖條件及讀者篩選必須同時符合；清除讀者篩選不會解除固定範圍，明細與 CSV 也保留相同限制。條件互相衝突時顯示無資料，不擅自放寬。若主檔已刪除，原限制保留並標示已移除項目，請 admin 確認後調整。
  7. 需要試算時才選「自訂試算」。例如 sale_total / count；只支援 count（台數）、sale_total（車價合計）、average_price（平均車價）、數字及 + − * / 與括號。公式不會修改訂單或財務，除以零會明確顯示無法計算。
  8. 預覽 → 發布。預覽不儲存；「儲存草稿」不影響讀者。「儲存並發布」會同時保存並發布，不必先按儲存。操作列會固定顯示；離開未儲存內容前會提醒。
  9. 複製、還原與取消發布。複製後是新的私人草稿；還原版本也只變更草稿，確認後再發布。取消發布會同步封鎖原連結、明細與匯出，不刪除歷史紀錄。不同分頁同時修改時，系統阻止舊版本覆蓋。

可選的來源訂單明細表

快速分頁：多頁列表可點第一頁、最後一頁，或輸入頁碼按前往／Enter。翻頁保留篩選、排序及圖表選取；側欄明細跳頁不離開報表。彙總表切換每頁筆數回到第一頁，不改變 Top N 與匯出範圍。

每張圖的「排序」與「日期層級」可獨立設定，再按「更新此圖」。例如第一張按年、第二張按日；未指定時沿用整頁設定。明細與 CSV 會跟隨該圖，其他圖的設定及篩選保留，不修改 admin 保存的設計。

點選圖表分類會直接篩選整頁圖表、來源明細與 CSV。同一張圖用 Ctrl／⌘ 複選代表「任一符合」，不同圖代表「同時符合」。上方顯示選取條件，可逐項移除，不必清掉其他日期或品牌篩選；圖表本身的固定條件仍然有效。日期選取會保留當時的年／月／日含義，改變顯示層級不會改寫已選取期間。合併的「其他系列」只開啟明細，不作全頁篩選。

admin 可在設計頁開啟明細表，選擇顯示欄位及每頁 10、25 或 50 筆，也可建立只有明細表的報表。明細與匯出同時遵守報表固定範圍及讀者篩選；單張圖表的額外條件只影響該圖與該圖下鑽，不會套到整份明細。匯出上限 5,000 筆，超過時須先縮小範圍。車主姓名只有 admin 明確選為明細欄位時才會顯示，不能將普通分類下鑽與此明細表混為一談；證件與聯絡資料不提供為報表欄位。

「DMIS 已確認實收」加總目前已確認收款；「歷史收款價（原始）」是匯入的舊值，不代表已收款或已結清。缺少收支資料會標為待補。「舊報表銷售來源（比對用）」依歷史原車行名稱分為馭盛、網路平台、店內員工、展場及車行；新訂單使用目前通路名稱。這與目前通路類型不同，也不改變傭金歸屬。堆疊系列可依合計或名稱正反排序；相同舊分類在堆疊與圓環使用一致顏色。

「原型號文字」以型號文字分組，不因 DMIS 年式主檔不同而拆開；「原報表能源分類」只供歷史比對，與 DMIS 能源別分開，不能拿來修改傭金規則。歷史公司禮券／匯款、平台贈品及公司贈品可分欄查看；它們是原始記載，不表示已發放。原空白顯示「原始未填寫」、缺欄顯示「原始欄位未提供」，不拿零值代替；新訂單顯示「非歷史匯入」，請回訂單確認實際獎勵。

「原報表車行／平台名稱」會依舊表規則移除一般空白並轉大寫，以便比對同名群組，不會修改合作車行資料或合併訂單。查看時選擇的原報表能源與固定條件取交集。既有明細欄位的順序在預覽與儲存時會保留，新勾選的欄位接在最後。

查看報表時，先選期間、月份與車行；品牌、能源、日期圖表層級及原報表比對條件收在「進階篩選」。進階條件套用後會自動展開並提示已使用幾項，避免忘記仍有篩選。「清除我的篩選」不會解除 admin 設定的固定範圍。

資料表可增加第二分類與附加指標，例如同表列出月份、歸屬車行及台數。點分類仍可查同一組來源訂單，CSV 保留多欄。DMIS 已分配台數獎金只統計已有分配紀錄的金額，不是待結算試算；車行傭金支出可能已含獎金，兩欄不可再相加，亦不代表已付款。

目前不支援自由畫布、樞紐分析、同期比較、排程寄送或連接 Google 試算表。各頁與原報表的資料差異，請看該頁「資料口徑與說明」。
