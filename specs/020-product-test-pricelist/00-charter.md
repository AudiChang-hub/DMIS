# 00 — Charter：產品定價測試頁面（020-product-test-pricelist）

## 背景

在討論如何讓使用者在產品頁「一目瞭然」看到分期資訊後，
決定先建立一個測試頁面驗證 UI 概念，確認方向後再正式重構現有產品頁。

## 目標

- 在「產品及零件管理」App 新增第三個子項目「測試頁面」
- 使用與「車型產品」相同的 `dms.product` 資料，不另建模型
- 在分期明細中加入「分期公司」欄位，供測試填入（如：和潤、遠信）
- 表單採單頁式佈局：基本資訊、售價、分期方案全部直接可見，無需切換 Tab

## 範圍

- **新增**：`dms.product.installment.line.finance_company` 欄位（Char）
- **新增**：`views/product_pricing_test_views.xml`（測試列表 + 測試表單 + action）
- **新增**：menu item「測試頁面」（`menu_dms_product_root` 下第三組）
- **不修改**：現有產品頁（`product_sku_views.xml`）與車型產品功能

## 驗收標準

- 選單「產品及零件管理 → 測試頁面」可正常開啟
- 列表顯示：內部代碼、車種名稱、年份、現金價、分期筆數
- 表單單頁顯示：基本資訊 + 售價 + 分期方案列表（含分期公司欄位）
- 可直接在表單內新增 / 編輯 / 刪除分期方案，不需跳頁
- 現有「車型產品」功能不受影響
