# 目前狀態

核對日期：2026-11-12。

- 版本：**2.2.0**（`config/release_notes.py`，各版內容以此為準）；正式站 2.2.0（migration 至 0203）。本版：大數據分析樹狀勾選車型、每款一圖，解除車種／電車鎖定。獎勵為活動制（見 BUSINESS_RULES；舊表待收斂）。台數獎金依規則自動算。領牌填好即完成，之後可改。訂單頁 GET 只讀。尾款只在交車時登記。左側「訂金與費用」含其他費用，訂單表單不帶訂金欄位。不要求填調整原因，重大動作備註選填。訂單頁汰舊區不顯示「補助類型」（欄位保留），「舊車與報廢資料」在汰舊資料下方直接編輯並自動儲存（營運表單獨立 `old_vehicle` 區段）。訂單頁側邊列有唯讀「訂單總覽」（快捷鍵 O），可搜尋、複製。統一撥款對帳只對系統建立的分期單與平台撥款，入帳即同步收支（範圍見 BUSINESS_RULES）；收款明細可取消勾錯的「已確認」（已沖銷不可）；交車前確認只列配件清單；分期資料無「套用選取方案」按鈕。分期單「分期外應收」扣已核准折扣與舊車估價（撥款不跟著折扣）。只有選號方式「指定號碼」收選號費，訂金頁目前金額會列出。訂購單配件多時自動續頁，收款資料、確認事項與簽名固定在每聯最後一頁。付款方式可多筆（現金／刷卡／匯款／分期，車價＝合計，見 BUSINESS_RULES）。系統只給本店人員使用：無車行帳號、無代開單、無待接單（開單者即接單人），訂購單一律用本店公司（見 BUSINESS_RULES「訂單與接待」）。建立訂單七步（車款與車價→車主→汰舊→選號→加購項目與贈品（可略過）→訂金（列目前金額、填備註）→確認），選車卡片直接接單。訂單頁全面自動儲存、資料維護區草稿＋套用。發布規範見 [RELEASE_POLICY](../RELEASE_POLICY.md)。
