# 圖表呈現方式圖像選擇器

## 已確認範圍

採用 B 方案：只將設計器的六種呈現方式改為縮圖、名稱、用途說明與選取標記；保留既有表單值、驗證、自動預覽、草稿及發布機制，不改計算、資料庫或讀者頁面。

## 實作與驗收

- 使用程式內建 SVG 示意圖（假資料），不載入外部圖片或客戶資料。
- 雙欄選擇面板使用 dialog 頂層，避免設定面板 overflow 裁切；窄螢幕限制在視窗內並可垂直捲動。
- 原生 select 是送出的唯一值來源；無 JavaScript／不支援 dialog 時保留原生選單。
- 支援新增圖表、切換圖表、重開時定位目前選項；Enter／Space 選取、方向鍵移動、Escape 取消、關閉後焦點回到觸發按鈕。
- 取消、重選原選項不得產生變更；不同選項只送一次 change，沿用既有預覽與離開提醒。
- 驗證六種選項與後端一致、表單儲存相容，以及桌機／平板／手機模擬尺寸與鍵盤操作。
- 實作後執行自動測試、CI、T470P 部署、健康檢查及登入後唯讀驗收；不自動發布既有報表。

## 本機驗收紀錄

- 報表定向 106 項測試通過；六種呈現方式均可通過原預覽表單，無 migration。
- Chrome 隔離資料：Escape 取消後原值與版本保持不變、焦點返回觸發按鈕；方向鍵＋Enter 改為折線後自動預覽正常。
- 新增第五張圖也顯示圖像選擇器，選擇指標卡並儲存測試草稿後，重新載入仍保留折線與指標卡，無表單錯誤。
- 1440×900、820×1180、390×844 模擬尺寸：六個選項皆位於視窗內，選擇器沒有水平溢出；不是實體裝置驗收。
- 正式驗收只開啟、取消選擇器，不儲存或發布現有報表。
