# Charter — Django 訂單與庫存 MVP

## 背景

既有 DMIS 建於 Odoo，但第一線訪談確認新的核心工作是「手機建立訂單、紙本合約簽署後配車、跨門市庫存、交車待辦與文件追蹤」。此流程不再沿用 Odoo，改以 Django 建立新的行動優先 Web 系統。

## 目標

1. 使用者可用手機在客戶面前建立訂單並拍攝證件。
2. 訂單可產生一式兩份的紙本訂購合約。
3. 未上傳簽署合約不得配車。
4. 實體車輛可跨門市配車，且不得重複分配。
5. 首頁集中顯示全部門市的逾期與一般待辦。
6. 使用單一搜尋框跨欄位尋找訂單。

## 本期不做

- Odoo 功能延伸或資料搬移
- 最終訂購合約版型（待提供範本）
- 最終金額公式（先保留系統試算與人工調整）
- 聲明書套表（待提供範本）
- LicenseWatcher Ubuntu worker 實作
- OCR 引擎選型與正式辨識（先完成安全上傳、核對欄位與服務介面）
- 發票與進貨單號
