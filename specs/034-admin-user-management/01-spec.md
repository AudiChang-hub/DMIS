# 管理者帳號與權限維護

## 目標

讓系統管理者在 DMIS 介面內建立及維護內部帳號，不必進入 Django Admin，也不共用同一組密碼。

## 使用者故事

- 身為系統管理者，我可以建立顯示名稱、登入帳號與臨時密碼。
- 身為系統管理者，我可以停用離職人員並保留歷史操作紀錄。
- 身為系統管理者，我可以重設忘記的密碼，但不能查看既有密碼。
- 身為新使用者，我第一次使用臨時密碼登入後必須設定自己的密碼。
- 身為管理者，我可以看見帳號由誰、何時建立、修改、停用或重設密碼。

## 權限與防呆

- 只有 `is_superuser=True` 的啟用帳號可以進入帳號管理頁。
- 一般人員不顯示入口，直接存取回傳 403。
- 不提供永久刪除帳號，僅提供停用／重新啟用。
- 不可停用自己、不可移除自己的管理者權限、不可停用或降級最後一位啟用中的管理者。
- 密碼使用 Django 雜湊與既有密碼驗證器；資料庫與異動紀錄均不得保存明碼。
- 管理者重設密碼後，該使用者既有登入工作階段立即失效。

## 驗收

1. 管理者可搜尋、篩選、建立、編輯、停用、啟用及重設帳號。
2. 建立／重設時可產生並複製安全臨時密碼。
3. 勾選首次登入變更密碼後，其他頁面會被阻擋，完成變更後保留登入狀態。
4. 帳號異動紀錄顯示操作人與時間，但不含密碼。
5. 手機與電腦版均可閱讀及操作。
