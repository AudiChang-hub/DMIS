# 驗收標準（05-acceptance）— Metabase 車行月銷量與累計趨勢

## 功能驗收

- [x] 進入 `P3 通路銷售統計` dashboard 可看到三張圖：月銷量長條圖、累計銷量折線圖與 `P3-4 車行區域銷量排行（長條圖）`。
- [x] Dashboard 頂部可見 `領牌年月`、`銷售來源`、`能源類型`、`車行縣市`、`車行區域`、`車行名稱` 六個下拉式篩選器。
- [x] Dashboard 首次載入時，`領牌年月` 預設帶入最近一次套用腳本時計算的最近一年（12 個月份，含當前月份）。
- [x] Dashboard 首次載入時，`銷售來源` 不應預設帶入任何值。
- [x] 兩張圖都不應顯示空白領牌月份或 `(空白)` 月份圖例。
- [x] `P3-1 車行月銷量（長條圖）` 應維持首屏可閱讀的緊湊高度，不因展開全部 dealer 而造成過長捲動。
- [x] Dashboard 應新增 `P3-3 車行月銷量明細（表格）`，可列出所有符合篩選條件的 dealer 與月銷量。
- [x] `P3-3 車行月銷量明細（表格）` 應以每列三組資料的矩陣版型呈現，超出者自動落到下一列，並於銷量欄使用非藍色 heatmap 區分高低。
- [x] `P3-3 車行月銷量明細（表格）` 應先依領牌年月遞減分塊排列，不可在同一列中跨月份跳接。
- [x] `P3-3 車行月銷量明細（表格）` 欄頭不應顯示 `A/B/C` 後綴。
- [x] 選取指定 `領牌年月` 後，兩張圖與明細表都會同步縮小到相符月份資料。
- [x] 選取指定 `能源類型` 後，兩張圖、排行圖與明細表都會同步只顯示電車或油車資料。
- [x] 選取指定 `車行縣市` 後，兩張圖、排行圖與明細表都會同步只顯示該縣市的資料。
- [x] 選取指定 `車行區域` 後，兩張圖、排行圖與明細表都會同步只顯示該車行區域的資料。
- [x] 選取指定 `車行名稱` 後，兩張圖、排行圖與明細表都會同步只顯示所選車行。
- [x] `P3-4 車行區域銷量排行（長條圖）` 應依銷量遞減排列，能直接看出熱門地區。
- [x] 若資料列類型屬於 `網路平台`，`P3-4` 與 `車行區域` 篩選器都應將該資料歸類為 `網路`，不再顯示為 `未設定`。
- [x] 若資料列因 `display_dealer_name` 空白而在報表中顯示為 `馭盛`，則 `P3-4` 與 `車行縣市` / `車行區域` 篩選器也應以 `馭盛` 車行主檔地址顯示對應縣市與行政區，不得繼續落為 `未設定`。
- [x] 若資料列原始 `display_dealer_name` 為 `朋友推薦` / `代申請補助`，則在 P3 的 `車行名稱` 維度應顯示為 `馭盛`，且 `車行縣市` / `車行區域` 也應顯示 `馭盛` 主檔地址對應值，不得再顯示 `店內` 或落為 `未設定`。
- [x] 點擊 `P3-4 車行區域銷量排行（長條圖）` 內任一區域值時，其他圖表與表格應可吃到相同 `車行區域` 篩選；若點擊值為 `未設定`，也必須能 drill-through 或查看對應訂單。
- [x] 保留 `銷售來源` 篩選器時，兩張圖、排行圖與明細表仍可正常同步過濾。
- [x] `P3-2 車行累計銷量（折線圖）` 會依目前篩選條件顯示總累計銷量，且數值隨月份遞增、不會倒退。
