# 034 月度車行價目表工作台

## 目標

讓內部人員在同一頁完成每月車行價目表的整理、修改、發布及列印，不必在車型、售價與分期頁面之間反覆切換。

## 使用者故事

- 使用者可依品牌與月份建立價目表，並選擇複製上一期內容。
- 系統由車型主檔帶入機種、年份、啟用顏色、當日售價與分期方案。
- 使用者可在工作台直接調整售價、現金優惠、現金價、各期月付、分期公司、開辦費、顧客贈品、通路及備註。
- 使用者可新增或移除要顯示的分期期數欄位。
- 草稿可重複修改；發布時建立日期生效的售價與分期版本，並保存價目表快照。
- 已發布價目表不可直接覆寫，需建立修訂版。
- 使用者可用品牌主檔 LOGO，亦可在單一價目表覆寫 LOGO。
- 系統可產生 A4 橫式、適合直接交付車行的列印版面。

## 業務規則

1. 價目表以品牌、月份及修訂版號識別。
2. 月份一律正規化為該月一日；實際生效日可另行設定。
3. 發布只更新同一生效日的版本，並結束前一個仍有效的版本；既有訂單快照不回寫。
4. 分期月付有填值時，必須指定分期公司；開辦費可為零。
5. 顧客贈品是對外銷售說明，不自動視為訂單已贈送配件。
6. 已發布價目表只能列印或複製修訂，不可刪除或直接編輯。
7. 品牌 LOGO 僅允許經伺服器驗證的 JPG、PNG 或 WebP 圖片。

## 驗收條件

- 能建立、複製、儲存、發布及列印價目表。
- 發布後能依生效日查到新售價及分期版本。
- 舊訂單價格與分期快照不變。
- 品牌 LOGO 能在品牌維護與列印頁正確顯示。
- 桌機使用表格式批次編輯；手機使用單列堆疊閱讀且無 UI 重疊。
