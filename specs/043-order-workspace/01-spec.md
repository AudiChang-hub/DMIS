# 訂單三頁籤工作區

## 已確認

採 B：內部訂單詳情與編輯整合「訂單資訊、金額收支資訊、補助申請資訊」。切換不重新載入，不丟失未儲存資料；接待建立訂單與車行進度頁不受影響。

## 設計與邊界

- 重用現有訂單、營運收支、補助表單與服務，不另建帳務資料。
- 三個主要頁籤；配車、領牌、交付歸訂單資訊，紀錄收合於共用區。
- 成交條件與實收／成本分區，標示不同儲存範圍。明確按鈕儲存，非自動儲存金額。
- 各表單原地儲存、欄位錯誤定位、未儲存提示、離頁警告；保留後端版本衝突檢查。跨區更新不能靜默覆寫尚未儲存輸入。
- 成本、佣金、淨利及財務編輯沿用獨立授權；淨利仍需密碼解鎖。未授權不輸出財務表單。
- 補助申请金額不當作已收款；折扣不連動撥款、佣金與成本；計算結果不直接編輯。
- 舊網址及頁籤連結維持可用，舊營運資料入口可進入整合頁。

## 驗收

- 桌機、平板與窄版切換、鍵盤、表單輸入保留及錯誤定位。
- 訂單修改、收款／成本、補助及文件；完成後修正、取消狀態、修改紀錄。
- 未授权直接請求不可越權；未解鎖的回應不含淨利。
- 並行修改及過期版本拒絕覆寫；失敗保留輸入。
- Django 完整測試、相關 PostgreSQL 財務測試、前端測試、實際瀏覽器驗證。
- 1.11.0 發布：備份、標籤、部署、公開健康與登入流程驗證；不得假稱完成。
