# 2026-09-21 PPT：公告與訂單工作區

使用者已批准完整 B 方案及以下計算口徑。

## 確認範圍

- 公告閱讀頁只有 admin 可原頁修改／刪除；圖片置於內文之前，既有與新增圖片可排序，附件下載須驗證公告受眾。
- 下訂來源欄位並排。自然人的證件正反面必填，車主存摺、汰舊車主證件與存摺選填。沿用草稿附件與訂單附件，不複製為第二份檔案。
- 具 order_pricing 操作權限或內部財務編輯權限者可輸入臨時配件、售價及工資，未授權不得透過 POST 自訂金額。
- 收款統一使用 PaymentRecord，移除交付頁的重複輸入。財務畫面允許依原因調整應收，實收不預填；訂金與分期公司撥款分列。
- 新分期訂單客戶總應收＝牌險＋配件；尾款紀錄扣除已單獨列入的訂金，避免重複收取。舊訂單維持舊口徑，以 cash_receivable_v2 區分，不批次重算。
- 列印分期預估尾款＝列印應收－本單分期本金；不是每期金額乘期數，也不是實際撥款。費用表移除說明欄。
- 財務與折扣核定授權皆符合者可原頁套用折扣，仍保留原因、稽核、樂觀鎖。成本、佣金及撥款不因折扣變動。
- 人工車輛成本受同步保護。移除重複分期匯款確認及撥款試算說明，保留真正的收款紀錄。
- 汰舊、同一車主設定由下訂帶入；同一人帶入新車主姓名及證號、可沿用證件與存摺。舊存摺附件不擅自更改其所有人標示。
- 補助項目輸入、刪除即時計算合計；文件標示改為送件前備妥，不阻擋儲存草稿。圖片可放大，PDF 可預覽，其他格式顯示檔名下載卡。
- 各頁籤保留未儲存內容，區塊間距及小按鈕依主題配色統一。

## 資料與回復

0146 migration 只新增公告附件、圖片排序及新單口徑旗標，並擴充附件類型選項；既有旗標皆 False。不得對歷史訂單進行批次財務重算。
部署前使用既有腳本備份 PostgreSQL 與媒體；回復前版程式可保留新增欄位，舊程式不使用新欄位。若需移除新 schema，先封存新增公告附件與排序資料，不能直接反向 migration 丟失新資料。
