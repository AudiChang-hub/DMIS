# 正式版本與首頁版本歷程（B 方案）

- 本次發布建立 SemVer 1.0.0 基準，不回溯虛構舊版號。
- config/release_notes.py 為版本、台北發布日期、分類更新內容的唯一來源，最新版本由首筆推導。
- 首頁：最新版本展開、舊版本收合、完整日期、新增／改善／修正。編版前紀錄獨立收合，標示 Git 提交日期及來源，不能冒充發布日期。
- 保留 get_app_version() 內容雜湊、靜態資源快取鍵及檢查更新 API。正式版號獨立供使用者閱讀。
- vX.Y.Z 發布標籤指向通過 CI 的精確提交，部署前核對，不移動已發布標籤、不覆寫舊版本。
- CI 驗證格式、順序、日期、內容、相對基準提交的升版及舊歷程不可變。歷史 Python 僅以 AST literal 讀取，不執行。
- 不新增資料表，不開放公告管理者改版號，不變更授權、訂單或財務公式。

## 相容性與驗收

相容契約涵蓋外部 HTTP/整合介面、匯入匯出格式及文件化操作流程和資料保存規則。相容修正 PATCH、相容新增 MINOR、不相容變更 MAJOR；提高較高位時低位歸零。

測試重複／倒序版號、無效／未來日期、空內容、篡改舊版、漏升版、標籤不符。首頁與使用說明版號一致；一般人員可讀但不增加公司資料權限，更新 API 保持 12 碼雜湊。驗證桌面、平板、手機、深淺配色及鍵盤展開收合。完整 CI 後備份、核對標籤、部署、健康與線上功能驗證。

## 回復

無 migration。若部署失敗，保留失敗紀錄及標籤，回復前一已驗證程式，不刪除訂單或公告。後續修復以新修訂版發行。
