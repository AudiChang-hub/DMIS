# Spec — Django 訂單與庫存 MVP

## 訂單建立

- 訂單來源分為本店、合作車行、網路平台；後兩者須選來源名稱。
- 訂單不區分銷售門市；門市僅用於實體庫存的歸屬與存放位置。
- 車主類型支援本國自然人、外籍／居留者、法人。
- 本國自然人可上傳身分證正反面，並填寫姓名、生日、地址、身分證字號。
- 訂單只選車型與車色，送出後進入「待簽約」；不在填單當下配車。
- 訂金單次收取，記錄金額、日期與付款方式。
- 配件第一階段自由輸入名稱、數量、類型與金額。
- 選號分為不選號、指定號碼監控、一般領牌偏好。

## 合約與配車

- 訂單可產生適合 A4 列印的訂購合約，一式兩份。
- 紙本簽署後須拍照或掃描上傳。
- 未上傳簽署合約不得配車。
- 上傳簽署合約後，訂單進入待配車。
- 配車僅列出相同車型、車色且狀態為可銷售的實體車。
- 配車成功後立即鎖定車輛，不得分配給另一張有效訂單。
- 取消或更換配車須留下原因並釋放原車。

## 庫存

- 車型與車色由主檔維護者建立，其他人從清單選取。
- 油車以引擎號碼為唯一識別，電動車以車身號碼為唯一識別。
- 重複識別號碼須禁止建立並顯示既有車輛。
- 實體車記錄庫存歸屬門市、實際存放門市與車況。

## 首頁與搜尋

- 首頁預設顯示全部門市待辦。
- 待辦依已逾期、今日到期、即將到期、一般待辦排序並以顏色提示。
- 全域搜尋不要求先選欄位，需搜尋訂單編號、車主、電話、證件號碼、車牌、引擎號碼、車身號碼、來源、車型、車色與備註。
- 身分證字號在清單預設遮蔽。

## 已訪談但後續實作

- 合作車行領牌文件於實際交車後 3 個工作日內補齊。
- 合作車行尾款於實際交車後 7 個工作日內收清。
- 工作日排除週末與台灣國定假日。
- 託運交車以交給託運公司的時間為準，並追蹤託運及損壞資料。
- LicenseWatcher 自動監控並回傳候選號碼，最後由人員辦理選號。
- 取消須全額退還訂金，退款完成才算已取消。
