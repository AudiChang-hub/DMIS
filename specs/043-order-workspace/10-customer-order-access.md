# 我的訂單、贈送與客戶文件授權

## 已核准範圍

- admin 設定資料範圍 own / dealer / all。本人以 submitted_by 精確比對；合作車行再交集 source_id / source_type，最多整間車行，不依姓名、帳號字串或 Excel 內容推測歸戶。
- 查詢、客戶文件列印、贈送、調價獨立。order_documents 的查看及匯出須同時勾選；order_gift 的查看及操作須同時勾選。
- 車行不開放金額收支頁、補助管理及其附件。客戶合約的成交價、付款方式仍可見，這不是內部財務權限。
- 共用導覽及常用功能依範圍顯示我的訂單／本車行訂單／全部訂單。成立頁可直接列印客戶簽署文件，無須查詢權限。
- 其他配件名稱整格預設隱藏，僅 other 選項顯示；新增列同樣適用。

## 遷移與相容

- 0149 新增範圍。既有店內 profile 及未建立 profile 的舊制人員維持原全公司範圍；admin 可在帳號與權限的身分／訂單範圍調整。車行依本次核准預設 own，admin 可改 dealer。
- 不修改既有 kind、source、帳號啟用、三個車行功能旗標或 pricing 授權。新增 gift 延續原已授權 pricing，以及既有店內財務編輯權。新增 documents 延續原店內 orders.export 及車行 can_view_orders。
- 不修改訂單 submitted_by、金額、簽署檔、公司快照或任何舊 Excel 資料。scope revision / access version 遞增，使發布前開啟的舊表單不可覆蓋新設定。
- admin 的固定全公司管理範圍不受一般設定限制；車行即使非法寫入 all，仍不突破本人且同車行的範圍。
- 既有贈品可原樣保留；無贈送權限不可透過 POST 增加數量或改成其他品項。核定配件售價與工資不因偽造金額而改寫。
- 全公司營運、報表、庫存等獨立管理畫面仍依其專屬授權，不自動因訂單查詢授權開放；admin 設定本人範圍時須另按需求授權那些畫面。

## 驗證及回復

- 覆蓋跨人、跨車行、內部本人、root、無建立者、直接 URL、附件、列印撤權、贈送／調價分離、保留舊贈品、遷移保留現有旗標及 stale revision。
- 瀏覽器覆蓋其他欄位、動態新增、贈送歸零、手機版、成立頁列印，以及 admin 分別設定新權限。
- 發布前完整 CI、資料庫備份及最新正式帳號設定快照；發布後唯讀驗證 audi 的舊旗標／pricing 未變、範圍及新授權正確。
- 優先前向修復；回復舊程式會失去本人範圍隔離，必要時先停用外部入口，核對備份再回到已驗證版本。新增 grant 舊版不使用；不可用還原舊資料庫覆蓋發布後正常訂單。遷移反向不刪除管理者已設定的新 grant。
