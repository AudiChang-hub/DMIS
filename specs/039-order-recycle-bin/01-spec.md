# 正式訂單可還原刪除

## 已確認

- 使用者要求正式訂單刪除，接受可還原刪除、獨立授權、原因及稽核；與選車 B 方案一併交付。
- 不實體刪除訂單、附件或歷史；訂單編號不得重用。一般查詢、搜尋、報表及車行入口排除已刪除資料。
- admin 預設可用，其餘內部帳號須另授予「刪除與還原訂單」查看／操作；車行不可取得此內部權限。
- 全部訂單及明細提供刪除入口；確認頁顯示訂單識別、影響、原因和確認勾選。「已刪除訂單」提供查詢、分頁、刪除資訊及還原。
- 刪除不是取消交易或沖銷金流。仍配車、已領牌／交付、待退款、已結算獎金或未完成退款的實收紀錄，須先處理業務關聯，不能靠隱藏訂單跳過。刪除不改動原狀態、金額或財務快照。
- 後端必須檢查權限、POST／CSRF、版本、行鎖與其他編輯者；還原不重算歷史金額。

## 實作與驗證

- SalesOrder 增加可空刪除時間、操作者、原因；預設 manager 排除刪除資料，all_objects 僅供回收區及維護。
- 新 migration 僅加欄位，不移除資料；回滾程式前須先從業務頁還原，否則舊版會重新顯示已刪除訂單。
- 測試刪除／還原、重複與過期請求、稽核與金額不變、未授權／車行拒絕、關聯保護、列表／報表／媒體排除及 PostgreSQL 併發。
- 合併升版 1.5.0；完整測試、CI、備份、部署及真實 UI 驗證完成前不得標示交付。
