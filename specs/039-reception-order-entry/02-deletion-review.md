# 刪除申請與 admin 審核

2026-09-15 使用者明確授權：直接刪除，不移轉到新訂單；已完成訂單只能由 admin 刪除。

- 沿用可稽核的邏輯刪除，不實體抹除證件、金額或操作證據。
- 有刪除操作授權的內部人員提出原因，顯示「刪除確認中」；原作業狀態與統計在核准前不變。申請人可取消，admin 可駁回或核准；admin 可直接刪除。
- 只有有效的 admin root 可略過完成、領牌、收款、配車與結算限制；其他帳號不可透過 POST 繞過。
- 一個 transaction 內鎖定訂單及受影響關聯，核對版本與編輯鎖，保留申請、決定與影響紀錄。
- 已刪除訂單退出查詢、營運、報表與收款待辦；收款證據留存，不偽造退款。
- 解除配車；未領牌且未交車的預留車回可銷售，已有領牌／交付證據的車保持非可銷售狀態，不能假定已退回新車庫存。
- 作廢原單台數獎金分配（保留原列），結算台數、門檻及預計額重算；實際帳面合計扣除被刪除分配，其餘訂單既有分配不任意改寫，保留金額調整稽核。
- 還原須 admin 核對庫存未被重新配車／異動，恢復原關聯與獎金分配；衝突則整筆拒絕，不覆蓋新交易。
- 匯入須辨識回收區已刪交易，禁止同一來源交易再匯入而復活；仍保留原有重複檢查。
- 不直接刪除使用者截圖中的正式資料；本次驗證使用合成訂單。
