# 報表與單圖固定範圍

原站佣金頁有電動車、車行及排除空白型號等圖表固定條件。B 方案本增量先實作
DMIS 已有欄位的品牌、能源別、來源類型、原車行／平台與指定車型複選。
不是直接把 EV 前綴當作 DMIS 能源分類，也尚未宣稱補助／正則分群相容。

## 規則

- 發布設定新增可省略的 `fixed_filters`；報表與各 card 均可持有。
- 同欄 OR、不同欄 AND；報表、單圖、讀者三層取交集，不能覆蓋放寬。
- 空清單代表該層不限；互斥條件顯示無資料。原狀態與日期規則不變。
- 指定來源為原來源，不等於傭金歸屬；財務仍唯讀 DMIS 保存值。
- JSON 僅接受白名單欄位、每欄至多 200 個合法字串，不接受任意 ORM 或 SQL。
- 已移除主檔仍保留 ID 限制與提示；不自動變成全部資料。
- 預覽、發布、下鑽、CSV 共享查詢；固定條件列在報表、圖表、明細與匯出。
- 沿用草稿／版本／admin 權限，不新增 migration，不修改正式訂單或財務。
