# 新版簡報改善（2026-09-17，9 頁）

## 已確認需求

1. 首頁公告／版本頁籤不重新載入整頁，保留鍵盤與無 JavaScript 操作。
2. 下訂附件位於配件之後，桌機與手機排版一致。
3. 配件支援贈送（售價及工資為零）、預設售價／工資可依授權調整；唯讀顯示單件合計及含數量總額。
4. 解鎖淨利後下載不得停留在處理中。
5. admin 個別授權下單金額調整，不以店內／車行身分決定；包含自訂分期公司、期數、每期金額與開辦費。不得因此開放成本、佣金或其他客戶資料。計算結果仍自動計算。
6. 統一撥款對帳說明金額口徑、入帳操作及確認狀態；未確認的零差額不可暗示已收款。
7. 公告可指定合作車行，圖片上傳即時預覽，圖片亦須驗證公告受眾權限。
8. 列印牌險說明納入可編輯文案；依分類、關鍵字、已自訂篩選並呈現目前文字。
9. 送禮活動可確認刪除、保留稽核；建立時可選擇帶入啟用且標記年節送禮的合作車行。

## 相容與風險

- 沿用既有權限、財務快照、可稽核修改及檔案驗證，不修改既有正式訂單。
- 車價優惠不折減分期公司撥款、佣金與成本。
- 未授權帳號不可藉修改 POST 調價；計算欄位不可改寫。
- 活動刪除採邏輯刪除，從工作畫面移除但保存紀錄；不刪除合作車行。
- 發布前測試權限、金額、檔案存取、頁籤、手機版與資料遷移。

## 驗收方式

- `test_site_review_followup` 覆蓋明確授權、舊車行帳號授權／撤權、自訂分期不誤套同期期數方案、贈品歸零、附件位置、下載完成頁、公告圖片受眾與檔案驗證、活動刪除及零差額提示。
- 前端測試涵蓋頁籤鍵盤切換、公告受眾搜尋與批次勾選、圖片重新選擇／過期錯誤／檔案限制、自訂分期保留人工數值。
- 隔離合成資料驗收桌機與 390px 手機畫面，以及兩聯 PDF 長牌險說明換行。
- 自動瀏覽器選取本機圖片受擴充功能的檔案存取設定限制；上傳與受眾由後端測試、預覽生命週期由前端測試驗證，不宣稱已完成實際選檔瀏覽器驗收。
- 正式發布須完整 CI 通過，先備份資料庫與附件，再套用 0145 遷移、核對服務與功能；不改既有訂單或替正式人員開啟新授權。
