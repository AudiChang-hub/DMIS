# B 方案：視覺化報表工作台

## 已確認需求

- 13 張指定報表使用已發布版本，不重新建立重複草稿；既有 admin 查看限制不擅自擴大。
- 中央畫布顯示實際 DMIS 查詢圖表，選取後於右側調整設定。支援拖拉排序、調整寬高，以及鍵盤上移／下移與尺寸選單。
- 儲存並發布沿用版本檢查、交易與歷史還原；預覽不得寫入資料。
- 圖表以半寬／全寬網格編排，手機自動單欄；不是任意重疊的絕對座標畫布。
- 共用工具與管理者工具分列，維持原權限，不縮小文字。

## 技術邊界

既有 JSON 圖表增加可選 width（6、12）與 height（320–1200）欄位，舊資料使用半寬與自動高度。後端嚴格驗證，不接受任意 CSS。預覽沿用 edit 表單驗證與結果引擎，以隔離的唯讀 iframe 呈現，不修改財務公式、訂單或原始資料。最多八張圖表沿用既有限制。

## 驗收

驗證預覽不寫入、版面儲存發布與還原、舊設定相容、非法尺寸拒絕、非 admin 拒絕。瀏覽器驗證真實圖表、拖拉／尺寸、未儲存提醒與窄螢幕。部署與測試結果另記，不預先宣告通過。
