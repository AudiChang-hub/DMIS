# admin 授權、舊訂單分期與介面舒適度

使用者確認六項修正：舊訂單分期可選既有方案；admin 可開放原受角色限制的畫面／報表；
權限按主選單分類；顯示登入身分；改善全站間距；每項都提供可勾選的查看、操作、匯出。

## 方案與執行邊界

採局部修正：沿用授權模型、預覽／套用／歷程、既有訂單欄位與分期版本。
不另建角色系統、不重寫所有頁面；完整方案卡片與角色繼承不是本次範圍。

- 已套用授權者以 admin 的勾選為準，覆蓋舊 superuser／報表 audience 查閱門檻。
- 未套用者維持舊制；既有停用帳號仍不可登入。不得自動把所有人改為 superuser。
- 三項勾選都可保存，操作／匯出仍依賴查看。沒有現成操作／匯出入口的畫面，保存授權但不虛構功能。
- 只有 admin 可授權、撤權；帳號操作授權不包含提升管理角色、接管 admin 或重設其他高權限帳號。
- 報表設計／分類發布仍為 admin 專用管理流程，逐份報表授權是閱讀既有發布內容，不等於發布權。
- 權限依戰情首頁、全部訂單、營運總表、報表中心、資料維護區分組；資料維護再分車輛商品／通路人員／費率規則／工具與管理。
- 頁首顯示姓名與帳號，手機也可辨識當前登入者；不改帳號本身資料。
- 舊訂單使用原訂單日期的有效分期版本；公司與期數連動選單由已設定方案產生。
- 初次載入保留歷史公司、期數、每期金額、開辦費與快照；使用者明確選取方案或按「套用選取方案」才帶入。
- 無有效方案或歷史值不在主檔時可保留／人工修正，不靜默套用今天的版本；顯示版本依據。
- 以共用樣式增加區塊、標籤與表格留白，保留資料表水平捲動、手機導覽及固定儲存按鈕。

## 驗證

授權前後讀取／匯出／撤權、無法自行擴權、不可接管管理帳號、舊制相容與 migration；
舊訂單不同日期版本、保留歷史值、公司期數連動、讀取失敗／過期回應、儲存財務與快照；
登入身分、分組篩選與桌機／平板／手機版面。完整 CI 與 PostgreSQL 通過後備份、部署及正式站驗收。

本機定向回歸：156 項通過（1 項 PostgreSQL 專用跳過），分期選單 7 項前端測試通過。
Chrome 1440、768、390 寬度驗收：分類搜尋、120 個可勾選欄位、登入身分、手機固定導覽／儲存區正常，無頁面水平溢出。
隔離合成已完成訂單：開啟保留 12 期／每期 6,000／開辦費 0；選擇乙公司 36 期帶入 2,500／800，依 2025 訂單日期而非 2026 方案，填原因確認後儲存。
