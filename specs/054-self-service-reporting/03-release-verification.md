# 報表工作台第一階段：交付與驗證

日期：2026/09/07。此檔只記錄已驗證事項，不表示整個 B 方案或 Google Data Studio 全功能已完成。

## 使用入口

- 檢視：桌機頂部「報表中心」；手機「更多 → 報表中心」，可自訂加入快速前往。
- 編輯：資料維護區「報表設計管理」，僅 username=admin、is_active、is_superuser 同時成立。
- 新報表預設私人。admin 明確選「所有已登入的內部帳號」並發布後，其他帳號才可看。
- `python manage.py seed_report_templates`：首次空白安裝建立一份已發布的 admin 私人模板；已有任何報表則不新增或覆蓋。

## 已實作

1. 最多 8 張圖：長條、折線、資料表、指標卡；圖表可新增、移除、上下移動。
2. 分類：月份、品牌、車型、能源、原銷售通路、台數／傭金歸屬車行、領牌縣市。
3. 指標：訂單台數、訂單車價合計、平均訂單車價；支援受限四則試算。
4. 日期依據可選領牌日或訂單日，讀者可再用期間／品牌／能源別篩選。
5. 草稿／已發布定義獨立；預覽不儲存；發布一併儲存；版本衝突防止覆蓋。
6. 複製新私人草稿、最近 20 次版本還原入口、取消發布；完整歷史仍留資料庫。
7. 分組下鑽、來源訂單連結、同條件 CSV、瀏覽器列印／存 PDF。
8. 不提供匿名分享、不顯示車主個資、不允許任意 ORM 路徑／SQL／程式執行。
9. 手機明細轉卡片；編輯操作列固定於手機導覽上方；公式僅自訂試算時顯示。
10. 舊頁面的下鑽／匯出帶設計指紋；發布新版後舊連結提示重新開啟，不默默改用不同分類。

## 資料與金額邊界

來源只讀 SalesOrder 與 many-to-one 品牌／車型／通路；不聯結收付款或多筆明細造成倍增。
排除 draft、cancel_refund_pending、cancelled；領牌日期口徑還排除未領牌。
vehicle_price 是訂單車價，不是實收／收入／淨利；台數不是車行台數獎金的正式結算量。
歸屬車行依 commission_recipient 優先，否則 dealer 的 source；不把平台或本店當合作車行。
公式彙總採原資料再計算，不把群組平均二次平均；零除及數值超限明確顯示無法計算。
Top N 截斷有提示，完整彙總與顯示群組分開。公式最多 200 字／60 AST 節點／200 群。
