# 訂單多欄排序與單列導覽

- 桌機訂單列表提供各欄表頭排序；直接點擊新欄位追加排序，再次點擊同欄切換升降冪並保留順位。不需Shift或額外勾選；手機同樣直接點擊。無JavaScript時連結維持相同行為。
- 顯示優先順序、方向，提供清除排序；搜尋、狀態、每頁筆數及分頁保留排序，變更排序回第一頁。
- 車主姓名與訂單編號合併在同一欄，姓名在上、較小字的編號在下；兩種排序連結放在同一表頭，維持獨立排序能力，減少表格寬度。
- 後端白名單驗證、移除重複欄位，以主鍵穩定打破同值。領牌日期遞減時空值（未領牌）置前、遞增時置後；其他欄位維持空值置後。多條件排序仍遵循既有優先順序，排序不篩除未領牌訂單。日期指獨立成立日期，淨利沿既有公式，不寫入資料。
- 桌機頂部導覽與帳號工具同列；窄桌機縮減間距與輔助文字，手機沿既有導覽。選單不可被裁切。
- 登出維持 POST＋CSRF，改有邊框及圖示的明確按鈕。
- 測試：排序方向、多條件、非法參數、空日期、穩定分頁、搜尋保留、淨利精度；瀏覽器桌機／平板／手機與鍵盤驗證。完整CI、備份部署及正式站驗證。
