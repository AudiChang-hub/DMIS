# 選檔即時預覽 B 方案

- 各啟用車色與進階主圖共用同一預覽元件；選檔後在瀏覽器本機檢查與顯示，不自動上傳。
- 明示「尚未儲存」；取消此次圖片變更清空新選檔並恢復原圖／待補圖，不修改資料庫。
- 支援 JPEG、PNG、WebP，最多 8 MiB；檢查檔案大小、檔頭及圖片可解碼。錯誤檔案與檢查中的檔案阻擋送出，可取消或重選。
- 更換圖片清除同色移除勾選；勾選移除則清除新選檔，提示「儲存後移除」，取消恢復原圖。主圖對應仍遵循既有伺服器驗證。
- 防止快速重選／取消後舊的非同步預覽覆蓋新狀態；釋放不用的 object URL。無 JavaScript 時沿用伺服器上傳驗證。
- 預覽／錯誤狀態可由鍵盤與輔助工具操作，維持桌面、平板及手機版。
- 補前端狀態與競態測試、模板與伺服器回歸；以隔離資料做真實瀏覽器上傳／取消／儲存驗收。不操作使用者已選檔的正式分頁。
- 修正原有圖片維護流程的即時回饋缺口，發布 1.6.1；更新使用說明及僅管理者可見的版本歷程，無 migration。完整 CI、標籤、備份、部署及正式站只讀驗證。
